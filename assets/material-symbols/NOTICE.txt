Modified for OrbitUI: a 110-glyph subset, static SVG outlines at weights
200, 300, 400 and 500, optical size 24, fill 0, grade 0. The default is 300.
The static font uses weight 300 and is renamed OrbitUI Material Symbols Rounded.
SVG icons are exported from those same subset font instances, not a different
version of Google's web catalogue. Unweighted SVG paths alias weight 300.
Original name-table copyright and license entries are retained.
No Google endorsement is implied.

Rebuild offline with scripts/build-material-icons.py (fonttools 4.60.1).
selection.json pins the original inputs by SHA-256 and defines the subset.
generated.json lists checksums of the generated TTF and SVG files.
No runtime downloads, global font replacement, or variable-font support is
required. Development build tooling is not part of the runtime package.
