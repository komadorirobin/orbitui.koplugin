OrbitUI / Japan

Five original colour ornaments: a pine bonsai, red maple bonsai, sleeping
calico cat, maneki-neko and daruma. Intended for colour e-ink shelves.

These pieces join the normal ornament rotation; they are not author-bound.
Use the existing ornament browser to enable/disable pieces or the whole pack.
Tap to zoom; long-press for native size, height and spacing controls.
The pack retains its colours in night mode. Existing ornament frequency and
None settings are respected, as are all author-bust placement rules.

On the first completed install OrbitUI switches off the unchanged default
cactus.svg and template.svg, without deleting either file. Edited versions
and artwork in other packs are not switched off. You can re-enable the stock
pieces afterwards; this choice is not overwritten on later startups.
An already disabled Japan pack is respected, and its installation does not
switch off the old plants. Existing files and reader metadata are preserved.
Deleted files stay deleted after the pack's install marker has been written.

The PNGs preserve their generated alpha and provenance, without resizing or
re-encoding. They are static assets: no AI service, network request, animation
or on-device generation is needed. See prompts.json for prompts and hashes.

The artwork is separate from the software license. See ATTRIBUTION.txt.
