# OrbitUI 0.1.0-beta.2

Safer app-store/manual updates and independent ornament distribution.

OrbitUI is built on **SimpleUI by doctorhetfield-cmd** and **Bookshelf by
AndyHazz**, with their contributors' work. It includes and adapts both plugins;
this is not an official upstream release.

## Changes since Beta 1

- Ornament catalogs now come from
  [orbitui-addons](https://github.com/komadorirobin/orbitui-addons), keeping future
  artwork releases out of the plugin release list used by app stores. The six
  packs are unchanged: the initial mirror has identical ZIPs and preview images,
  stable pack IDs/versions, credits and compatibility folders.
- Existing installed packs, custom captions, artwork edits/deletions, placement
  and enablement are preserved. Old catalog/download URLs remain supported and
  the original release remains available for older clients. No pack needs to be
  removed or reinstalled just because its distribution repository changed.
- After successful startup from an OTA slot, OrbitUI can recognize a newer
  external release ZIP installed into its root. It verifies the complete file
  inventory, hashes, Lua syntax and unchanged bootstrap, then copies only those
  files into an inactive snapshot. Candidate code does not run during checking.
- The verified snapshot is selected only by the main process and requires an
  additional restart. The running code remains unchanged until then; the previous
  OTA snapshot is retained for rollback. Older/equal factory versions do not
  override a newer OTA installation.
- Failed startup or manual rollback does not automatically reselect the same
  external update. **Retry external installation** in the update menu offers an
  explicit retry after checking/replacing the external ZIP. Interrupted or invalid
  copies leave the current runtime selected.

## Install or update

**Existing OrbitUI users: install Beta 2 through OrbitUI's own updater first.**
Open **Tools > OrbitUI > Uppdatera OrbitUI**, enable preview releases, check for
updates and restart. Beta 1 and earlier do not contain the external-import logic.
No manual bridge, settings reset or ornament migration is needed. Bootstrap API 1
and all three bootstrap files remain unchanged.

For a first installation, download **orbitui.koplugin.zip**, not GitHub's source
archive. **OrbitUI replaces standalone SimpleUI and Bookshelf:** disable both,
keep their settings/backups and restart before installing OrbitUI. See the
[installation guide](https://github.com/komadorirobin/orbitui.koplugin/blob/v0.1.0-beta.2/README.md#installation).

Keep using OrbitUI's internal updater as the recommended path. **Storefront's
separate nested-plugin installation bug is not fixed by this OrbitUI release.**
Wait for a Storefront release containing
[PR #5078](https://github.com/ultimatejimmy/storefront.koplugin/pull/5078) before
using it to install OrbitUI. External installers must preserve the hidden OTA
directories; deleting the entire plugin directory also deletes code rollback.

## Verification and limitations

Lua/LuaJIT regression suites, translation checks, runtime ZIP validation and native
Linux archive/hash tests cover external snapshots, restart, rollback, corruption,
cancellation and immutable ornament migration. Public ornament downloads were
also tested through the real HTTPS and archive paths. These are **not device
tests**: physical app-store integration and the extra-restart UI still need
confirmation. The release remains an explicitly requested beta.

No upstream merge or new artwork is included. Bookshelf remains 5.5.4
(`982375a7`) and SimpleUI 2.7.5 (`7eb80f9e`). Settings and reading data are not
reset; code rollback does not restore old reading progress. Returning to Beta 1
also removes external-update detection and uses the original ornament channel.
Keep a separate backup and read [OTA recovery](https://github.com/komadorirobin/orbitui.koplugin/blob/v0.1.0-beta.2/docs/OTA.md).
