# OrbitUI 0.1.0-alpha.49

Manga miniatures and the expanded Solar Icon Pack, following the alpha.48
updater compatibility bridge.

## Changes

- Adds 14 transparent colour ornaments in **Manga** and **Manga II**, including
  Akira's motorcycle, Dungeon Meshi's mushroom, the Apothecary mortar, Nyanko
  Sensei, Brushbuddy, Ohmu, a mimic chest, Pochita, Turbo Granny, a transponder
  snail, a Kettenkrad, a camping tent, an armillary sphere and Cafe Alpha.
- Places these beside their matching series, including series boxes and
  individual volumes, rather than in unrelated random rotation. At most one
  series miniature appears per row; matched author busts retain priority and
  their existing multiple-bust exception. Tap for a larger image and info card.
- Updates pxlflux's Solar Icon Pack to **v1.1.0**: 60 additional motifs in each
  of **Solar Colour** and **Solar Mono**, for 220 icons per style. Instapaper and
  Z-Library receive their revised upstream artwork. Existing icon identities
  and selections remain intact; choose new icons individually as before.

The ornament packs install once, additively, without replacing custom images,
metadata, theme selections or previously deleted pieces. If your shelf theme
selects particular ornament packs, include Manga and Manga II to show them.
Frequency None and pack/individual off switches still apply.

The miniatures are AI-generated, with original image bytes, transparency,
provenance and credits retained. Character-inspired pieces are unofficial fan
art, not official merchandise or a blanket license to the underlying designs.
Solar SVGs retain their source artwork and CC BY 4.0 attribution.

## Updating

**Install alpha.48 and restart KOReader before updating to this release.**
This package exceeds the older updater's 64 MiB limit. Alpha.48 accepts up to
128 MiB with bounded downloads and the same integrity/rollback protections.

From alpha.48, use **Uppdatera OrbitUI > Check for updates**, with preview
releases enabled, install alpha.49 and restart KOReader. Allow roughly 350 MiB
of free space in addition to existing installations. For a manual installation,
use `orbitui.koplugin.zip`, not GitHub's source-code archive, and follow
`MIGRATION.md` if an existing OTA activation record is present.

Readers still on alpha.47 or earlier cannot install this ZIP through that old
updater. Install the small [alpha.48 bridge](https://github.com/komadorirobin/orbitui.koplugin/releases/tag/v0.1.0-alpha.48)
first; the old updater does not automatically skip the larger latest release
to offer the bridge. Keep an installation/settings backup.

Bootstrap/API 1, component pins, reading data and synchronization ownership
remain unchanged. Code rollback retains copied artwork: disable Manga and
Manga II before rolling back to alpha.48 or earlier, whose planner lacks their
series matching. New Solar icons also require alpha.49 or later. Earlier
dashboard/theme rollback caveats remain in effect.

## Validation Scope

Release gates cover complete Lua/LuaJIT and translation suites, the sealed
runtime and original artwork bytes, outgoing-history checks, native OTA from
the actual published alpha.48, CI, and downloaded draft/public asset checks.
The user confirmed installing alpha.48 and restarting before this publication.
Physical Bigme rendering/touch acceptance of the new artwork remains open;
headless tests are not device tests. Existing environment/source-artwork skips
remain, without new exceptions.
