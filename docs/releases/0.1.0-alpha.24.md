# OrbitUI 0.1.0-alpha.24

A frontal photographic Thomas Mann shelf ornament.
**Preview release: physical reader appearance and migration still need
device testing.**

## Changes

- Mann now uses Pauline Ahrens's frontal 2022 photograph of Gustav Seitz's
  bronze portrait. Background masking and proportional resizing preserve the
  photographed face, colours, mounting block and thin bronze plinth. No
  generative redrawing, invented base or retouching.
- The Swedish author biography, book matching and tap-to-zoom remain intact.
  Updated photo credits and source records are included. Photo/cutout terms
  are CC BY 4.0; the sculpture's separate rights basis is documented alongside.
- An independent v4 migration replaces only exact known default Mann images,
  including alpha.23. Older completion markers do not block this replacement.
  Custom images, edited captions, placements, disabled pieces, native overrides,
  linked paths and deleted files are preserved. Interrupted updates can retry.
- All other ornament images, including Hemingway, Joyce and Woolf, are unchanged.

No upstream merge, reading-data change or synchronization change. Bookshelf
remains at 5.3.1 through `74b825bb`, SimpleUI at 2.7.5 through `b58dfefb`.
The older AI-assisted Mann bitmap is not included in the package or public
Git ancestry; this new photographic cutout does not relicense that older image.

## Updating

Open **Tools > OrbitUI > Uppdatera OrbitUI > Check for updates**, with
**Include preview releases** enabled. Install alpha.24 and restart KOReader.
Alpha.23 and earlier alpha releases can update directly with bootstrap/API 1
unchanged. Allow roughly 250 MiB free in addition to installed versions.

Use **orbitui.koplugin.zip**, not GitHub's source-code archive. No separate
ornament download is required. Code rollback retains copied artwork and
metadata; keep backups if you need to restore earlier ornament images.

## Verification

Release gates cover 88 Python checks, 389 OrbitUI cases on Lua and LuaJIT,
351 passing Bookshelf suites, all 13 SimpleUI test files and 41 translation
catalogs. Two native-SQLite suites and existing font-dependent cases remain
explicit skips. Original-photo/museum pixel audits run locally with source
caches; CI skips the four cache-dependent checks.

The release process verifies the sealed runtime, downloaded draft assets,
native OTA from the actual alpha.23 installer, CI and anonymous public OTA.
These headless checks do not replace a device test of silhouette, base
alignment, author adjacency, zoom and preserved custom ornament settings.
