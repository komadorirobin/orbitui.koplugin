# OrbitUI 0.1.0-alpha.37

Preview release: Bookshelf 5.4.3 and the reviewed October 12 SimpleUI update,
with OrbitUI's Library/Manga profiles and shelf customizations preserved.

## Changes

- Explicit Auto view mode can use different styles at the top level and inside
  a group, for example an author list opening into physical bookshelves. The
  two levels are stored independently for Library and Manga. Existing unset
  view choices retain their previous behavior.
- The top panel keeps a consistent height when switching shelves with different
  cover captions. Per-chip text, custom templates and above/bottom placement
  remain available in grids and physical shelves.
- Folder/author drill-ins get distinct but repeatable ornament arrangements.
  Session shuffling, manual choices, author-matched busts and the ordinary
  one-ornament-per-row limit remain intact.
- Opening a selected cover restores the wallpaper around its outline instead
  of leaving a white ring. Wallpaper-only packs can also be used as themes.
- Clock and status text can update in place instead of rebuilding the whole
  module. Raster and metadata caches are bounded, and read-status changes
  invalidate cached series data. No device-level speedup is claimed.
- SimpleUI improves D-pad focus and hides Uncategorized by default in native
  metadata browsing, with a toggle to show it. This does not delete books or
  change OrbitUI's Library/Manga membership.
- Bookshelf is pinned to `ed135103c687a09e0443ec8c3119033adf579b0f` (5.4.3).
  SimpleUI is pinned to `213a3c70f4e8670394c4ac6db63baaea1660ba3a` (2.7.5).

## Updating

Use **Uppdatera OrbitUI > Check for updates**, with preview releases enabled.
Install and restart KOReader. Alpha.36 and earlier alpha installations can
update directly through the unchanged bootstrap/API 1. For manual installation,
use `orbitui.koplugin.zip`, not GitHub's source archive.

Series slipcases, read/total badges, completion fading, custom icons, dock/Bento
layout and BookOrbit sync ownership are retained. No artwork, books, reading
history or external plugins are changed. This release adds no settings
migration. Keep a settings backup: upgrades from before alpha.33 still include
Bookshelf 5.4's theme-storage migration, which code rollback does not reverse.
New Auto level preferences survive rollback but are ignored by earlier code.

## Validation Scope

Release gates cover full Lua/LuaJIT integration and component suites,
translations, sealed runtime packaging, outgoing-history/artwork checks and
upgrade/rollback from published alpha.36, including anonymous release discovery
and download. Focused regressions cover Auto levels, caption height, ornament
seeds, bounded caches, clock refreshes and live metadata invalidation.

Existing native SQLite/font dependency skips and four external artwork-source
audit skips remain. Physical-reader acceptance is still outstanding, especially
Auto levels, captions and ornament revisits on both profiles, wallpaper opening
effects, Home clock ticks/suspend/resume and colour/night rendering. Headless
checks are not device-level rendering or OTA tests.
