# OrbitUI 0.1.0-alpha.9

Choose Material icon line thickness individually, with a lighter default.
**Preview release: native touch, SVG appearance and e-ink contrast still need
testing on the Bigme B7 Pro.**

## Changes

- Adds **Line thickness...** to the Material picker with 200 (Thin), 300 (Light),
  400 (Regular) and 500 (Medium). All 110 icons include all four offline SVG variants.
- Makes **300** the default, including for older Material selections without an
  explicit weight. Icon identities stay the same; Nerd Font and custom PNG/SVG
  choices are unaffected.
- Previews the thickness before saving. Tap an icon to save its icon/weight pair
  for that button only. Changing the preview or cancelling does not save anything.
- Remembers each explicit weight independently, including across restarts and
  OTA-slot changes. The Bookshelf image-capable icon picker has the same control.
- Retains alpha.8's picker crash fix and the existing SVG rendering path. No
  variable icon font, whole-pack replacement or global weight setting is introduced.

Books, reading progress, synchronization, layout and upstream baselines are
unchanged. No settings reset or recovery patch is required on a working install.

## Updating

Open **Tools > OrbitUI > Uppdatera OrbitUI > Check for updates** with
**Include preview releases** enabled. Install alpha.9 and restart KOReader.
You can update directly from alpha.8 or earlier alpha releases.

For manual installation use `orbitui.koplugin.zip`, not the source-code archive.
Read [OTA and recovery](https://github.com/komadorirobin/orbitui.koplugin/blob/v0.1.0-alpha.9/docs/OTA.md)
before replacing an installation with an active OTA slot. Bootstrap API 1,
the three bootstrap files and previous-version rollback remain unchanged.

## Verification and limits

Verification covers the full Lua and LuaJIT suites, 23 focused icon tests,
6 recovery tests, 35 Python tests, all 41 translation catalogs and the sealed
runtime inventory. The existing two native-SQLite and one opt-in exhaustive
geometry suite skips remain. Packaged OTA checks use the published alpha.8
installer with KOReader's native archive/hash modules to verify activation,
restart, rollback and rejected incomplete downloads.

Headless tests do not replace device testing. Check all four previews, save
different weights on different buttons, reopen a saved icon, cancel without
changes, and verify restart plus native menu/dock sizing and dimming. The older
alpha.6 startup-crash cause remains unconfirmed; its variable-font UI path is
not used by this release.
