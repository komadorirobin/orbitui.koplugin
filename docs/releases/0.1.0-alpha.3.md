# OrbitUI 0.1.0-alpha.3

Reviewed upstream updates and clearer whole-package updating.
**Preview release: the new build still needs testing on the Bigme B7 Pro.**

## Changes

- Integrates Bookshelf 5.3.0 and fixes through `21e005a7` (176 upstream commits).
- Integrates SimpleUI `main` through `3444cc9c` (21 upstream commits), including
  per-element fonts, module opacity/frames and metadata/refresh improvements.
- Names the update entries in Bookshelf, SimpleUI and OrbitUI **Uppdatera OrbitUI**.
  All use the common updater; neither component can update independently.
- Retains the custom dock, BookOrbit integration, reading-profile opening paths,
  independent backgrounds and external patch/plugin compatibility seams.
- Preserves existing settings, link and cache paths instead of moving them via
  Bookshelf's new storage migration. SimpleUI does not disable other plugins or
  rename patches automatically.
- Validates all 41 translation catalogs without the former failure exceptions.

## Update from alpha.2

Open **Tools > OrbitUI > OrbitUI updates > Check for updates** in alpha.2.
Keep **Include preview releases** enabled (the alpha default). Install and restart
KOReader. After updating, the menu entry is named **Uppdatera OrbitUI**.

For a first installation, use `orbitui.koplugin.zip`, not a source-code archive.
Follow [the migration guide](https://github.com/komadorirobin/orbitui.koplugin/blob/v0.1.0-alpha.3/docs/MIGRATION.md) and keep the old standalone plugins
disabled. Existing settings and reading data are retained.

This build keeps OTA bootstrap API 1 unchanged. The updater verifies the complete
package and retains the previous code for rollback. See [OTA and recovery](https://github.com/komadorirobin/orbitui.koplugin/blob/v0.1.0-alpha.3/docs/OTA.md).

## Verification and limits

Lua/LuaJIT checks pass: 31 Python tests, 80 OrbitUI integration cases, 343 Bookshelf
suites and 13 SimpleUI test files. Release checks also cover package inventory/SHA-256,
native archive extraction, deferred activation, restart and rollback. Existing
native SQLite/font/UI and exhaustive-geometry test skips remain documented.

The first release has a positive initial device report, not full acceptance.
This merged build still needs checks for UI/layout, profiles, suspend/resume and
OTA/recovery on the actual device. No performance improvement has been measured.
