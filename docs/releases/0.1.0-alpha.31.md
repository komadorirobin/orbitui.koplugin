# OrbitUI 0.1.0-alpha.31

Preview release: reviewed SimpleUI upstream update with OrbitUI compatibility fixes.

## Changes

- Integrate 16 SimpleUI commits through `6f34fb76`, including a faster reader
  return path, metadata/cover cache improvements and shared menu hooks that
  prevent margins shrinking on repeated opens. Bookshelf remains at `74b825bb`.
- Add an optional tabbed titlebar with configurable ordering and search. Keep
  the current titlebar style, custom icons and existing library layout rather
  than automatically replacing them.
- Add an independent destination after closing a book, initially derived from
  the existing preferences. Explicit Home actions still go Home.
- Include wallpaper darkening, corrected day/night tint behavior, restored
  module backgrounds after pagination, clock alignment and independently sized
  Currently Reading/Coverdeck badges.
- Preserve OrbitUI's Bento top margins, live dock-margin refresh, fresh section
  labels, legacy badge sizes and button-only titlebar backgrounds. Temporary
  database or cover-decoding failures remain retryable instead of being cached
  as permanent empty results. Existing series boxes and ornaments are unchanged.

## Updating

Use **Uppdatera OrbitUI > Check for updates**, with preview releases enabled.
Install and restart KOReader. Manual installations use `orbitui.koplugin.zip`,
not GitHub's source archive.

The stable bootstrap and API 1 are unchanged; alpha.30 and earlier alpha
installations can update directly. Books, reading history, sync ownership,
artwork and existing preferences are preserved. New close-target preferences
are initialized without deleting the older settings; older runtimes ignore
the new options on code rollback. No general UI modularization is included.

## Validation Scope

Release gates cover full Lua/LuaJIT integration and component suites,
translations, the sealed runtime package, CI and native OTA upgrade/rollback
from the published alpha.30, including anonymous discovery/download.
Headless regression tests cover the new cache and navigation paths and the
preserved OrbitUI presentation. Two native SQLite suites and existing
font-dependent cases require additional runtime dependencies; four original
artwork pixel audits need external source caches. Artwork is unchanged.
Physical reader acceptance of the new tabs, reader-return behavior, day/night
backdrops and layout remains open. No measured device speedup is claimed.
