# OrbitUI 0.1.0-alpha.54: optional ornament add-ons test alpha

This is the final planned test alpha before beta, not beta approval. The existing
layout/settings upgrade has been tried on a reader; isolated fresh setup and the
new add-on workflow still need physical-device acceptance.

## What changes

- **Smaller plugin:** ornament artwork is no longer bundled or installed on a
  fresh setup. Existing native artwork, themes and customizations stay intact.
- **Optional add-ons:** install, preview, update, enable/disable and view credits
  under **OrbitUI settings > Add-ons > Ornament add-ons**. Choose **Check ornament
  updates**, install a pack, then **Use in current theme**. No account is needed.
  Packs start disabled unless adopting an existing local selection.
- **Six packs:** Manga, Japan, Ukiyo-e Gallery, Modernists, Authors and Authors II.
  Manga is one visible pack/version, retaining legacy subfolder paths only for
  compatibility. Future ornament updates need no OrbitUI code release.
- **Placement per pack:** **Match books (default)** keeps author busts and manga
  pieces beside matching books. **Random** uses the ordinary shuffled pool.
  Unbound decorations remain mixed in both modes. Choices persist through restart
  and updates without changing theme selections. Ordinary pieces remain limited
  to one per row; multiple matching author busts can still share a row.
- **Information cards:** all 60 cards have Swedish and English versions. Swedish
  KOReader uses Swedish; other languages use English. Custom captions win. Existing
  users receive these cards by explicitly installing/updating the relevant pack.

Downloads use verified HTTPS, size limits, ZIP/per-file SHA-256 checks, data-only
validation and inactive staging. Managed updates preserve custom images, captions,
added files and deletions. The original artwork and its credits are unchanged;
licenses differ by pack and include noncommercial material. Artwork is not all
covered by OrbitUI's code license. Review **Credits and licenses** before reuse.

Bookshelf 5.5.4 (`982375a7`) and SimpleUI 2.7.5 (`7eb80f9e`) remain unchanged
upstream baselines. No upstream merge or new artwork is included.

## Update and recovery

Enable preview releases in **Uppdatera OrbitUI**, update from alpha.53 and restart
KOReader. Keep a separate current backup of settings and the working installation.
Do not enable standalone SimpleUI or Bookshelf alongside OrbitUI.

Code rollback does not roll back add-ons or preferences. Alpha.53 does not read
the managed add-on directories, so newly downloaded ornaments may disappear from
view on rollback; old native folders remain. Uninstalling a managed pack retains
custom files and does not delete old native folders. Never restore old reading
progress as part of a UI rollback. See [add-on recovery](../ADDONS.md) and
[OTA recovery](../OTA.md).

## Reader checklist before beta

1. Upgrade and restart; verify the existing layout, shelves, reading state,
   wallpaper, icons and old ornaments remain intact.
2. Open the add-on menu, refresh the catalog, preview/install Manga and another
   pack, enable them in the current theme, and inspect zoom, credits and info.
3. Switch matching/random placement, page forward/back and restart. Confirm
   settings persist and disabled packs stay disabled. Check Swedish/English cards.
4. Try an offline/cancelled download and a reinstall/update with a custom caption
   and deleted image; confirm no active artwork or edits are lost.
5. In a separate fresh KOReader settings copy, test the guide, Skip/Cancel/Apply,
   folders, restart, preset switching and operation without BookOrbit accounts.
   Verify no ornaments are installed until explicitly selected. Do not erase the
   working configuration for this test.

Automated Lua/LuaJIT, archive and native installer tests do not replace these
device checks. Report problems before approving the first beta.
