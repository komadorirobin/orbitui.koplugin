# OrbitUI 0.1.0-alpha.42

Preview release with the reviewed Bookshelf 5.5.2 and SimpleUI updates.

## Changes

- Custom series images now appear on physical-shelf slipcases. Both custom
  images and first-book covers retain their proportions, with the read-total
  above the picture. Missing or unreadable custom art falls back to the cover.
  The wider minimum, native perspective and member-spine marks remain.
- Random Book gains an **On tap > Open book directly** option. Showing the
  selected book in the top panel remains the default.
- SimpleUI offers shared white/gray background tones, frames and opacity
  controls, with Full-width/Floating navigation layouts. Copy-only migrations
  preserve existing choices and legacy keys. Quick-setting button transparency
  and independent titlebar-button opacity remain supported.
- Home stays alive beneath its main menu and returns correctly from temporary
  plugin screens. Delayed restoration cannot take over Library/Manga navigation.
- Shared UTF-8 text helpers and bounded author labels prevent oversized list
  context on books with long or multiple author names.
- Bookshelf's transparent wallpaper panels now also work without its native
  C blitter. This primarily targets affected devices; no Bigme speedup is claimed.

Reviewed pins: Bookshelf `c7a9db2ca1c21ef6a38715e74306fe7f514ba807`,
SimpleUI `7eb80f9e570e6351c55f501f91e1a29c1442b756` (still versioned 2.7.5).
Library/Manga profiles, per-chip sizing/labels, ordinary face-out books,
ornaments, custom icons and BookOrbit sync ownership are retained.

## Updating

Use **Uppdatera OrbitUI > Check for updates**, with preview releases enabled.
Install and restart KOReader. Alpha.41 and earlier alpha installations use the
same stable bootstrap/API 1. For manual installation choose
`orbitui.koplugin.zip`, not GitHub's source archive.

Keep the previous installation and settings backup. Code rollback leaves book
progress and settings intact, but new surface choices are not mirrored to older
appearance keys. Earlier theme-storage, grouped-order, ledger and module-edit
rollback caveats still apply. No artwork is changed by this release.

## Validation Scope

Release gates cover full sequential Lua/LuaJIT integration and component suites,
all 43 translation catalogues, sealed package and outgoing-history/artwork audits,
native installer upgrade/rollback from published alpha.41, both CI jobs,
downloaded draft hashes and anonymous public discovery/download/install.

Existing SQLite/native-font skips, absent Bookends parity checkout and four
external artwork-source audit skips remain. Tests cover custom-art proportions,
fallback and buffer ownership, copy-only appearance migration and presets,
legacy dock APIs, long Unicode author labels and deferred screen restoration.
Physical Bigme acceptance remains open: check custom series art, completion,
colour/night mode, existing wallpaper/dock appearance and Home/menu navigation.
Headless tests do not establish device rendering or performance.
