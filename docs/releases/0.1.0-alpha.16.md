# OrbitUI 0.1.0-alpha.16

Adds more Bookshelf ornaments and improves series sorting.

## Changes

- Adds more Bookshelf ornament variations to the OrbitUI ornament collection.
- Improves series sorting for Bookshelf shelves and grouped library views.
- Keeps existing settings and rollback behavior intact.

## Updating

Install via the published OTA update in KOReader or by downloading the packaged ZIP from GitHub Releases.
