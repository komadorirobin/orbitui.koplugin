# OrbitUI 0.1.0-alpha.44

Preview release with naturally sized book spines and partially filled series boxes.

## Changes

- Series-box books no longer expand or shrink to fill all available width.
  Comparable page counts determine spine thickness on a shared scale. Unknown
  counts use a neutral default; reflowable reader-layout counts do not make a
  book appear thicker after changing the reading font or layout.
- Books pack to the left, leaving a shaded interior on the right when there
  is space. The shadow follows the actual occupied part of the box.
- Long series show the first complete spines that fit, up to eight. A separate
  **+N** indicates additional local volumes not drawn, not missing or unread
  books. The **read/total** still includes every member, and tapping opens the
  complete series as before.
- Cover area and proportions are retained, along with shelf/series choices for
  **Hardcover**, **Paperback** and **Manga / tankobon**. Those menu labels remain
  Swedish when KOReader uses Swedish, and English otherwise.

Upstream pins remain Bookshelf 5.5.2
`c7a9db2ca1c21ef6a38715e74306fe7f514ba807` and SimpleUI 2.7.5
`7eb80f9e570e6351c55f501f91e1a29c1442b756`. No upstream import, artwork change,
settings migration or reading-data change is included. Existing profiles,
ornaments, icons, sorting and BookOrbit sync ownership are retained.

## Updating

Use **Uppdatera OrbitUI > Check for updates**, with preview releases enabled.
Install and restart KOReader. Alpha.43 and earlier alpha installations use the
same stable bootstrap/API 1. For manual installation choose
`orbitui.koplugin.zip`, not GitHub's source archive.

Keep the previous installation and settings backup. Code rollback restores
the earlier box presentation without changing reading progress or settings.
Earlier appearance, theme-storage, grouped-order, ledger and module-edit
rollback caveats still apply.

## Validation Scope

Release gates cover sequential full Lua/LuaJIT integration/component suites,
all 43 translation catalogues, sealed runtime and outgoing-history/artwork
audits, the published alpha.43 installer's upgrade/rollback, both CI jobs,
downloaded draft hashes and anonymous public discovery/download/install.

Focused coverage includes short/long series, page-count provenance and fallback,
status independence, DPI/size/thickness controls, whole-prefix packing,
colour/night painting, empty-space shadows and separate count labels. Existing
SQLite/native-font skips, absent Bookends parity checkout and four external
artwork-source audit skips remain. Physical Bigme checks of partial interiors,
thickness, small/large boxes and label legibility remain open. Headless tests
and shape-only previews are not device acceptance.
