# OrbitUI 0.1.0-alpha.11

Four additional Solar icons, selectable individually without replacing any
existing icon choices. **Preview release: native rendering and touch selection
still need testing on the Bigme B7 Pro.**

## Changes

- Adds **Database**, **Cloud Download**, **Download Minimalistic** and **Library**
  to both **Solar Outline** and **Solar Line Duotone**, now 80 icons per style.
- Search by these names in the individual icon picker. Library is under Reading;
  the other three are under System. Home/dock/system icons and Bookshelf's
  image-capable icon library use the same sources.
- Keeps existing icons, Material weights, reading data, settings, rendering code
  and upstream baselines unchanged. The additions are offline SVGs, not fonts or
  whole-pack presets.

See the [icon guide](https://github.com/komadorirobin/orbitui.koplugin/blob/v0.1.0-alpha.11/docs/ICONS.md).

## Updating

Open **Tools > OrbitUI > Uppdatera OrbitUI > Check for updates** with
**Include preview releases** enabled. Install alpha.11 and restart KOReader.
Alpha.10 and earlier alpha releases can update directly. Bootstrap API 1 and
the three bootstrap files are unchanged; previous-version rollback is retained.

For manual installation use `orbitui.koplugin.zip`, not the source-code archive.
Read [OTA and recovery](https://github.com/komadorirobin/orbitui.koplugin/blob/v0.1.0-alpha.11/docs/OTA.md)
before replacing an installation with an active OTA slot.

## Verification and limits

The Lua and LuaJIT suites include 30 focused icon tests, 6 recovery tests and
39 Python tests. All 41 translation catalogs and the sealed runtime inventory
are checked. The existing two native-SQLite and one opt-in exhaustive geometry
suite skips remain. All eight added SVGs have desktop previews at 144 and 40
pixels. Native OTA checks use the published alpha.10 installer and KOReader's
archive/hash modules to test activation, restart, rollback and rejected
incomplete downloads. These checks do not replace physical-device testing.
