# OrbitUI 0.1.0-alpha.20

Wall-mounted Ukiyo-e Gallery frames, richer artwork information and the reviewed
SimpleUI updates. **Preview release: physical Bigme layout, touch and recovery
acceptance remain outstanding.**

## Changes

- Gallery frames now hang above the plank, with a gap proportional to shelf
  height. All 27 museum images retain their original packaged pixels, colours
  and proportions. Native tap-to-enlarge and scrollable information remain.
- Replaces short visual notes with longer Swedish, AI-assisted summaries of
  primary museum sources, with measurements and source URLs. The cards label
  these as OrbitUI commentary, not the museums' original text or a direct
  translation. No paid ornament-pack artwork or text is included.
- Updates untouched alpha.19 gallery placement/info defaults automatically.
  Custom captions, explicit positioning/size overrides, deleted ornaments,
  artwork, pack enablement and theme choices are preserved. The migration is
  independently marked, atomic per file and retryable after interruption.
- Includes five reviewed SimpleUI commits through `b58dfefb`: clock visibility
  on layout saves, Unicode lowercase fallback, unified start-view access,
  quote catalogue revisions and quote/clock/action-list margin improvements.
- Fixes a regression in that upstream layout change: editor drafts no longer
  mutate the stored comparison snapshot. Adding/removing modules works across
  repeated saves without re-enabling deliberately hidden clock elements.

Bookshelf remains at 5.3.1 through `74b825bb`; SimpleUI remains version 2.7.5
with the newer reviewed commits. Retains independent Bento top margins,
cover-forward books, alphabetical series blocks, author-bound busts and the
ordinary-ornament row limit/session shuffle. Reading data and synchronization
ownership are unchanged; BookOrbit remains the intended Hardcover progress writer.

## Updating

Open **Tools > OrbitUI > Uppdatera OrbitUI > Check for updates**, with
**Include preview releases** enabled. Install alpha.20 and restart KOReader.
Alpha.19 and earlier alpha releases can update directly. Bootstrap API 1 and
all stable bootstrap files are unchanged. Allow roughly 250 MiB free space
in addition to existing installations.

The runtime `orbitui.koplugin.zip` contains the complete gallery and migration.
OTA users do not need the optional `orbitui-ukiyoe-gallery.zip`; that archive
is for a fresh manual ornament installation under
`koreader/settings/bookshelf/ornaments/`. Do not manually overwrite a customized
gallery to obtain this update: OrbitUI's migration preserves those edits.

For manual plugin installation use `orbitui.koplugin.zip`, not GitHub's source
archive. [OTA and recovery](https://github.com/komadorirobin/orbitui.koplugin/blob/v0.1.0-alpha.20/docs/OTA.md)
explains installation and rollback. Code rollback does not undo saved UI edits
or gallery metadata updates, and never resets reading progress or artwork.

## Verification

Release gates cover complete Lua/LuaJIT suites (307 OrbitUI cases, 57 Python
checks, 351 Bookshelf suites and all 13 SimpleUI test files), 41 translation
catalogs, all 27 original-image pixel comparisons, sealed package inventory,
native OTA from the published alpha.19 installer, downloaded draft-asset checks,
both CI jobs and anonymous public OTA. Two Bookshelf native-SQLite suites remain
explicit skips. Headless checks do not establish physical-device acceptance.
Check wall spacing and tap/info scrolling, Home/custom-screen layout editing,
clock visibility, startup choice and text margins on the Bigme.

Woolf and Dostoevsky adaptations.
