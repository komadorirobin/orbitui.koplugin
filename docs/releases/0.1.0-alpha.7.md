# OrbitUI 0.1.0-alpha.7

Material icons: individual selection and safer SVG rendering.
**Preview release: startup and rendering on the Bigme B7 Pro still need testing.**

## Changes

- Material Symbols Rounded now uses the matching bundled SVGs in pickers,
  dock/quick actions and system buttons, instead of loading a separate text
  font. This removes the font-loading/native-button path implicated in the
  reported alpha.6 startup failure. The exact device crash site is unconfirmed
  because a crash log was not available.
- Removes Material from **Icon Packs**. It is a catalogue for choosing one icon
  at a time, not a preset that replaces multiple icons. Opening or cancelling
  the catalogue changes nothing; selecting an icon changes only that slot.
- Retains all 110 offline icons, including `manga` and `comic_bubble`, searchable
  categories, existing Nerd Font/custom images and Bookshelf's image-capable
  icon picker. Other user-installed icon packs are unchanged.
- Reads existing alpha.6 `material:name` overrides as SVGs without resetting
  settings. Packaged image paths still resolve across OTA version directories.
- Includes an optional, non-writing recovery userpatch for alpha.6 installations
  that cannot reach the UI. It is not installed or enabled automatically.

To change one icon, open **OrbitUI > Appearance > Home appearance > Icons**,
choose the system or quick-action icon to edit, then **Material Symbols Rounded...**.
Bookshelf's image-capable icon picker also has a **Material** category.

No layout, book files, progress, sync settings or upstream baselines are changed.
The old alpha.6 bulk action did not record previous icon values, so this release
cannot reconstruct overwritten custom choices. It preserves current settings
instead of restoring an unrelated old snapshot.

## Updating

You can update **directly from alpha.5**; do not install alpha.6 first.
Open **Tools > OrbitUI > Uppdatera OrbitUI > Check for updates** with
**Include preview releases** enabled. Install alpha.7 and restart KOReader.

An already-working alpha.5 does not need the temporary recovery patch. If you
installed `2-orbitui-material-safe-mode.lua`, remove/disable it after updating,
then restart to make saved Material selections visible again.

For a manual installation use `orbitui.koplugin.zip`, not GitHub's source archive.
Read [OTA and recovery](https://github.com/komadorirobin/orbitui.koplugin/blob/v0.1.0-alpha.7/docs/OTA.md)
before replacing an installation with an active OTA slot. Bootstrap API 1,
the three bootstrap files and previous-version rollback remain unchanged.

## Verification and limits

Verification covers the Lua and LuaJIT suites, 16 focused icon tests, 6 recovery
tests, the asset inventory, all 41 translation catalogs and the sealed package.
The existing two native-SQLite and one opt-in exhaustive-geometry skips remain.
Native archive/OTA checks cover full-package hashes, missing-file rejection,
activation, restart, rollback and truncated downloads, including an upgrade
from the published alpha.5 installer.

The user reports alpha.5 starts again after rollback. Alpha.7 has not yet been
confirmed on the affected device. Headless tests do not prove native UI rendering,
touch behavior or e-ink contrast. Verify a single manga-icon selection, cancel,
mixed old/new icons, resizing, night mode and persistence after restart.
