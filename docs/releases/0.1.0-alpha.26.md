# OrbitUI 0.1.0-alpha.26

Compact series boxes and balanced ornament spacing.
**Preview release: box appearance and touch interaction still need device testing.**

## Changes

- Identified local series occupy one cover-facing box in the physical shelf
  view. The front shows the first available volume in numeric reading order;
  an in-box label shows the series and actual local volume count.
- The box side grows with the number of volumes, from 8% extra cover width to
  a maximum of 30% at ten or more volumes. Large series still display their
  real count. Boxes follow the existing cover-size setting and shelf geometry.
- Tap or double-tap opens the series with individual volumes. Long-press keeps
  the native series menu. Pagination and letter navigation use the same compact
  display list. Group drills expose every eligible member, including long series.
- Filtered/section-local boxes retain their scope after restart. Source metadata,
  reading status and book files are not modified. Grid/list views, remote
  catalogues and folders without identified series metadata remain unchanged.
- Ordinary shelf-end ornaments are centred in their available free space,
  balancing the gap to the shelf edge and nearest book. Book positions and
  pagination are unchanged by this spacing correction. Author-matched busts and
  intentional negative-padding placements retain their existing behavior.
- No upstream merge, new artwork, settings migration or sync change is included.

## Updating

Open **Tools > OrbitUI > Uppdatera OrbitUI > Check for updates**, with
**Include preview releases** enabled. Install alpha.26 and restart KOReader.
Alpha.25 and earlier alpha releases can update directly; bootstrap/API 1 and
the three stable bootstrap files are unchanged. Use **orbitui.koplugin.zip**,
not the source-code archive.

Code rollback returns to expanded series without reverting settings or reading
data. Allow roughly 250 MiB free in addition to installed versions.

## Verification

Release gates include complete Lua and LuaJIT suites, translation validation,
the sealed runtime ZIP, downloaded draft-asset checksums, CI, native OTA from
the actual alpha.25 installer, and anonymous public OTA checks. Native-SQLite
and font-dependent cases retain their documented environment skips.

Headless regression tests cover grouping, numeric order, pagination/counts,
filtered restoration, 120-volume drills, bounded box geometry and native
callback routing. They do not replace device rendering or touch tests. Compare
short/long series, day/night mode, portrait/landscape, cover sizes, author drills,
page turns and return after reading. Also check left/right ornaments with both
full and sparse shelves. Use the updater's restore option if needed.
