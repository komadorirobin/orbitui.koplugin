# OrbitUI 0.1.0-beta.5

SimpleUI 3.0, adapted to preserve existing OrbitUI layouts and settings.

OrbitUI includes and adapts **SimpleUI by doctorhetfield-cmd** and **Bookshelf
by AndyHazz**, with their contributors' work. This is an independent combined
plugin, not an official release by either upstream project.

## Changes since Beta 4

- SimpleUI 3.0: detailed statistics and charts, live Bento layout preview,
  accent/secondary colours, optional Inter/Geist fonts, Tiny Critter and updated
  native dialogs and configuration controls.
- Retains existing percentage/stacked Bento layouts and OrbitUI defaults. The
  new fixed-span model activates per screen only after an explicit width or
  movement edit. Font selection and Tiny Critter remain optional.
- Preserves custom icon sources, navigation guards, BookOrbit/KOSync links,
  shared book details and owner-safe teardown of external widget wrappers.
  Settings migrations retain old keys for rollback; failed statistics queries
  remain retryable rather than appearing as an empty day.
- Bookshelf remains 5.5.5 plus PR #544's Shelf size fix. No artwork, ornament
  channel, stable bootstrap/API or reading-data changes.

SimpleUI's official 3.0 ZIP contains newer code than its Git tag/main. This
release imports the reviewed ZIP, records its exact digest and retains the
upstream Git baseline separately in
[sources.json](https://github.com/komadorirobin/orbitui.koplugin/blob/v0.1.0-beta.5/sources.json).

## Install or update

Existing users: use **Tools > OrbitUI > Uppdatera OrbitUI**, enable preview
releases, check for updates and restart KOReader. Beta 4 can update directly;
no bridge is needed.

For a first installation, download **orbitui.koplugin.zip**, not GitHub's source
archive. **OrbitUI replaces standalone SimpleUI and Bookshelf.** Disable both
and restart first; retain their files and settings for backup. See the
[installation guide](https://github.com/komadorirobin/orbitui.koplugin/blob/v0.1.0-beta.5/README.md#installation).

## Verification and limitations

Release gates cover the complete Lua/LuaJIT suites, translations, exact sealed
ZIP inventory, outgoing-history/artwork/secret audits and native OTA upgrade,
restart and rollback from public Beta 4, including downloaded public bytes.
These are headless tests, not physical-reader acceptance. The new layout editor,
charts, fonts, colours/night mode, Tiny Critter, keyboard/touch/D-pad and external
plugin interactions still need Bigme/device feedback. This remains a prerelease.
