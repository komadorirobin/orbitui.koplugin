# OrbitUI 0.1.0-alpha.4

Shared Home and library features in one OrbitUI interface.
**Preview release: testing on the Bigme B7 Pro is still required.**

## Changes

- Opens the same Bookshelf book-detail panel from Home, the library and shared
  search results. Native status, collection, rating and Hardcover-link actions,
  registered external plugin actions and Home module settings remain available.
- Adds **Visa den här hyllan på Hem** (Show this shelf on Home) to shelf-chip
  long-press menus, with book-row and cover-carousel display modes. Pins resolve
  the current shelf contents rather than saving a static book list. Each pin
  starts on its own Home page and can be moved into a Bento layout.
- Groups Home, Library, Manga, Home shelves, Appearance and the common updater
  in **OrbitUI settings**, while preserving existing settings and advanced controls.
- Shares search between Home and the library, with whole-library, literature,
  manga/comics and current-shelf scopes. Book actions and opening routes remain
  consistent with the view that launched the search.
- Keeps independent carousel positions and the original Want to Read deck.
  Empty or deleted source shelves show an empty state instead of unrelated books.
- Preserves native book-opening paths, profile execution and external patch
  hooks. No extra Hardcover status/progress writer is introduced.

The component upstream baselines are unchanged from alpha.3. This is a feature
release, not a performance-optimization pass; no new speed improvement is claimed.
See [controls and compatibility notes](https://github.com/komadorirobin/orbitui.koplugin/blob/v0.1.0-alpha.4/docs/SHARED_UI.md).

## Updating

Open **Tools > OrbitUI > Uppdatera OrbitUI > Check for updates** and keep
**Include preview releases** enabled. Install the update and restart KOReader.
The embedded component update entries lead to the same OrbitUI updater.

For a first installation, download `orbitui.koplugin.zip`, not a source-code
archive. Follow [the migration guide](https://github.com/komadorirobin/orbitui.koplugin/blob/v0.1.0-alpha.4/docs/MIGRATION.md)
and keep standalone SimpleUI and Bookshelf disabled.

The stable bootstrap API 1 is unchanged. Existing settings, links and reading
data are retained. Previous-version rollback remains available in the updater;
see [OTA and recovery](https://github.com/komadorirobin/orbitui.koplugin/blob/v0.1.0-alpha.4/docs/OTA.md).

## Verification and limits

The release is checked with both Lua and LuaJIT test suites, including 41 new
shared-UI regression cases, translation validation and runtime-package checks.
Native SQLite/font/UI and exhaustive-geometry test skips remain documented.

Headless tests do not establish device acceptance. Check the new panels,
Home/Bento layouts, navigation and reading profiles on the reader, as well as
suspend/resume and OTA/rollback. No physical-device verification is claimed.
