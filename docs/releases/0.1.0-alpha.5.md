# OrbitUI 0.1.0-alpha.5

Bookshelf 5.3.1 and OrbitUI navigation/pagination fixes.
**Preview release: testing on the Bigme B7 Pro is still required.**

## Changes

- Removes the unwanted line through transparent pagination in folder/list views
  and full-screen modules. The hero, chip and list panels and dock separator
  retain their independent appearance settings.
- Integrates 11 Bookshelf upstream commits through `9633b031`, including 5.3.1.
  Key/D-pad navigation is corrected for spine shelves, detail tabs, cover
  selection and the shelf editor; Back cancels shelf/top-panel resizing.
- Keeps footer focus/page-turn refreshes above the OrbitUI dock instead of
  repainting the wrong screen band. Upstream's focus-ring coverage is retained.
- Opens whole series, authors, genres and collections from book-detail pills,
  including Home's shared panel. Current-shelf search preserves that group;
  ordinary shelf groups and folders retain their filters, and profile scope
  and saved shelf filters are preserved.

SimpleUI remains at `3444cc9c` (2.7.2-beta.5). No additional reading-status or
Hardcover progress writer is introduced. Existing settings, links and reading
data remain in their original locations. No device speedup is claimed.

## Updating

Open **Tools > OrbitUI > Uppdatera OrbitUI > Check for updates** with
**Include preview releases** enabled. Install and restart KOReader.
The embedded Bookshelf and SimpleUI update entries open the same OrbitUI updater.

For a first installation, download `orbitui.koplugin.zip`, not a source archive.
Follow [the migration guide](https://github.com/komadorirobin/orbitui.koplugin/blob/v0.1.0-alpha.5/docs/MIGRATION.md)
and keep standalone SimpleUI and Bookshelf disabled.

Bootstrap API 1 is unchanged. Previous-version rollback remains available;
see [OTA and recovery](https://github.com/komadorirobin/orbitui.koplugin/blob/v0.1.0-alpha.5/docs/OTA.md).

## Verification and limits

The release is checked with Lua and LuaJIT suites, translation validation,
runtime inventory/hash checks and native archive/OTA installation tests.
The existing native SQLite/font/UI and opt-in exhaustive-geometry skips remain.

Headless checks do not establish device acceptance. Verify transparent folder
pagination, footer focus with the dock, whole-group navigation/search, reading
profiles, suspend/resume and OTA/rollback on the reader. Full physical-device
verification is still outstanding, so this remains an alpha prerelease.
