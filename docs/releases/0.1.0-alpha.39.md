# OrbitUI 0.1.0-alpha.39

Preview release with the reviewed October 14 Bookshelf and SimpleUI updates.
OrbitUI's Library/Manga profiles and existing shelf customizations are retained.

## Changes

- Bookshelf gains Favourite first sorting and discovers document formats
  registered by other plugins, without treating image files as books or
  automatically extracting covers that may require network access.
- OPDS-PSE streaming/resume support and an optional record-action API let
  compatible external reader plugins offer actions on catalogue entries.
- SimpleUI adds a persistent finished-book ledger, manual-book entries and
  consolidated statistics/reading-goal controls, plus show/fade/hide choices
  for finished books and series grouping per native library view.
- A new Flow carousel style is available as an option. Classic remains the
  default, and BookOrbit/custom-shelf sources keep their navigation state.
- Folder-cover planning, shared background/shadow rendering and translations
  are updated. OrbitUI retains retryable caches, safe patch-wrapper teardown,
  custom icon fonts, module labels, independent Bento gaps and dock geometry.
- Bookshelf is pinned to `aeada050f90921b748dcef0ae2f88367bd0e1b69` (still
  versioned 5.4.4); SimpleUI to `84a9c0e96152c81c9879b484840ad4cd22ab1580`
  (still versioned 2.7.5).

Bookshelf PR #508 is not included. OrbitUI keeps its existing cover-coloured
series slipcases, read/total badges and finished-series appearance, all-face-out
books, per-chip cover captions/sizes and author-matched ornaments. No artwork
or external plugins are replaced. BookOrbit remains the owner of its sync.

## Updating

Use **Uppdatera OrbitUI > Check for updates**, with preview releases enabled.
Install and restart KOReader. Alpha.38 and earlier alpha installations can
update directly through the unchanged bootstrap/API 1. For manual installation,
use `orbitui.koplugin.zip`, not GitHub's source archive.

Back up settings before updating. New migrations copy legacy fade/grouping and
finished-book/manual-count settings without deleting the old values. Code
rollback preserves settings but does not mirror new ledger edits into older
code. Upgrades from before alpha.33 still include the theme-storage migration,
which code rollback does not reverse. Keep the old install and backup together.
Book files and reading history are not moved or reset.

## Validation Scope

Release gates cover full sequential Lua/LuaJIT integration and component suites,
all 43 translation catalogues, sealed packaging, outgoing-history/artwork
checks, and native installer upgrade/rollback from published alpha.38, followed
by anonymous public release discovery/download.

Existing native SQLite/font dependency skips, absent adjacent Bookends parity
checkout and four external artwork-source audit skips remain. Physical Bigme
checks are still outstanding: finished/manual totals and BookOrbit status edits
through restart; finished visibility and external filters; per-view grouping;
Flow carousel rendering/swipes in colour/night mode; icons, Bento, labels and
dock reflow; Favourite first and optional plugin-format/OPDS-PSE integrations.
Headless checks are not device-level rendering or OTA tests. No measured
performance improvement is claimed.
