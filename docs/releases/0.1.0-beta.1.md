# OrbitUI 0.1.0-beta.1

The first public beta of a combined Home and visual-library interface for KOReader.

**Built on SimpleUI by doctorhetfield-cmd and Bookshelf by AndyHazz, with their
contributors' work.** OrbitUI includes and adapts these plugins; it is not a
from-scratch replacement or an official upstream release. Thank you to both
creators for the foundation that makes this project possible.

- SimpleUI: https://github.com/doctorhetfield-cmd/simpleui.koplugin
- Bookshelf: https://github.com/AndyHazz/bookshelf.koplugin
- Introduction, credits and installation: https://github.com/komadorirobin/orbitui.koplugin#readme

## Why OrbitUI?

SimpleUI's modular Home screen and navigation meet Bookshelf's visual library
in one plugin, with shared book details, search, settings and updates. Configure
your own library sections and folders; no personal fiction/manga setup or online
account is required. Add the optional Reading dashboard, pin shelves to Home,
adjust bindings/captions/series presentation, and install only the ornament packs
you want. Ornament updates are independent of plugin releases.

See the [feature guide](https://github.com/komadorirobin/orbitui.koplugin/blob/v0.1.0-beta.1/docs/FEATURES.md)
for the OrbitUI additions and controls.
The underlying Home, library, themes and series/ornament systems are upstream work.

No upstream merge or new artwork is included. The integrated baselines remain
Bookshelf 5.5.4 (`982375a7`) and SimpleUI 2.7.5 (`7eb80f9e`). The six optional
ornament packs remain on `ornaments-1`; their licenses are separate from the code.

## Install or update

**OrbitUI replaces standalone SimpleUI and Bookshelf. Do not run them together.**
Keep a full backup, disable whichever standalone plugins you use and restart
before installing. Download **orbitui.koplugin.zip**, not GitHub's source archive;
extract it into KOReader's `plugins/` directory and restart. The path must be
`plugins/orbitui.koplugin/main.lua`. Neither predecessor is needed for a fresh
installation. Follow the
[installation and migration guide](https://github.com/komadorirobin/orbitui.koplugin/blob/v0.1.0-beta.1/docs/MIGRATION.md).

Existing OrbitUI users can update through **Uppdatera OrbitUI** with preview
releases enabled, then restart. Bootstrap API 1 is unchanged. Existing settings
and ornament folders are retained; the automatic settings snapshot is not a
full backup of images, books, databases or other plugins.

This release was explicitly approved after the user's existing-layout and
ornament-menu testing. It is still a beta: broad fresh-install/device/patch
compatibility, including native-only Bookshelf adoption, needs further feedback.
Read the rollback caveats before returning to older code. Report problems to
OrbitUI with device/version/reproduction details, never private settings backups.
