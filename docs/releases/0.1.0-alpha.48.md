# OrbitUI 0.1.0-alpha.48

Small compatibility update preparing the updater for larger artwork packages.

## Changes

- Accepts update ZIPs up to **128 MiB** and expanded contents up to **256 MiB**.
- Large downloads can take up to ten minutes, helping slower reader Wi-Fi.
  API/checksum requests retain three minutes and socket blocking stays bounded.
- Keeps SHA-256 checks, HTTPS verification, safe staging, startup rollback,
  the 32 MiB individual-file limit, 2,000-file cap and 1 MiB manifest limit.
- Build-time checks now reject packages outside the updater's limits, and
  native upgrade tests exercise the installed version's release-size check.

This bridge retains alpha.47's interface, settings, artwork and upstream pins.
The pending manga ornaments and Solar v1.1.0 icons are deliberately **not in
this release**. They will arrive in the larger follow-up after this bridge is
installed. No original image is resized, and no reading data is migrated.

## Updating

Use **Uppdatera OrbitUI > Check for updates**, with preview releases enabled.
Install **0.1.0-alpha.48**, then **restart KOReader**. Verify that About shows
alpha.48 before installing the subsequent artwork update.

This release itself stays under 64 MiB, so the older updater can install it.
Simply including a raised limit in a larger ZIP would not work: the old
updater rejects that ZIP before reading its code. Bootstrap/API 1 is unchanged.
For a first/manual installation use `orbitui.koplugin.zip`, not the source ZIP.

Keep your installation/settings backup. Code rollback remains available, but
rolling back to alpha.47 or earlier also restores the old size limit. Earlier
dashboard/theme rollback caveats remain in effect.

## Validation Scope

Gates include complete Lua/LuaJIT and translation suites, the sealed runtime,
unchanged-artwork/bootstrap and outgoing-history audits, native OTA from the
actual published alpha.47, large-payload boundary tests, CI and downloaded
draft/public asset verification. No physical Bigme acceptance is claimed.
Existing SQLite/native-font and external artwork-source audit skips remain.
