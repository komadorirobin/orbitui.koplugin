# OrbitUI 0.1.0-alpha.47

Preview release with an optional reading dashboard and titles on series covers.

## Changes

- **Reading dashboard** adds a BookOrbit-inspired first Home page with a larger
  continue-reading card, daily/weekly/streak statistics, in-progress books,
  the existing reading goal, and Want to Read / Recently added cover rows.
  Enable it under **OrbitUI settings > Reading dashboard > Show dashboard as
  first Home page**. Existing pages, wallpaper and dock settings are retained.
- Each cover row shows three books with its own **previous/next arrows and page
  counter** when needed. Paging one row does not change the other or the Home
  page. End arrows are disabled; shorter lists clamp the remembered position.
- Tap a book to open it; hold it for the existing book panel. Goal/statistics
  cards open their settings. The dark continue-reading card can be made light.
  The page uses existing local books/caches, the configured Hardcover goal or
  local annual goal, without adding a new BookOrbit sync or download client.
- Long-press a shelf chip > **Series box title > On the cover (bottom)** to
  place the series name on a readable, box-coloured plate inside the cover.
  The image can extend into the previous title strip while keeping its aspect
  ratio. The choice is independent per Library/Manga shelf; **Below the cover
  (default)** restores the previous presentation. Folder cards and individual
  book captions are unchanged.

The new Home layout and title placement are opt-in. Existing profiles, artwork,
icons, MAL cutouts, read-total counts, binding choices and sync ownership remain.
Upstream pins stay at Bookshelf 5.5.2 `c7a9db2ca1c21ef6a38715e74306fe7f514ba807`
and SimpleUI 2.7.5 `7eb80f9e570e6351c55f501f91e1a29c1442b756`.
No upstream import, artwork change or reading-data migration is included.

## Updating

Use **Uppdatera OrbitUI > Check for updates**, with preview releases enabled.
Install and restart KOReader, then enable the dashboard if desired. Alpha.46
and earlier alpha installations use the same stable bootstrap/API 1. For manual
installation choose `orbitui.koplugin.zip`, not GitHub's source archive.

Keep the previous installation and settings backup. **Disable the dashboard
before rolling back to alpha.46 or earlier**, so the older runtime is not left
with an unsupported dashboard page. Your older Home pages are retained. Code
rollback keeps the series-title preference, which older code ignores. Earlier
appearance, theme-storage, grouped-order, ledger and module-edit rollback
caveats still apply.

## Validation Scope

Release gates cover full Lua/LuaJIT integration/component suites, translation
catalogues, sealed runtime and outgoing-history/artwork audits, the published
alpha.46 installer's upgrade/rollback, both CI jobs, downloaded draft hashes
and anonymous public discovery/download/install.

Focused coverage includes additive layout changes, independent paging, source
failures, cached goals, cover/progress refreshes, book tap/hold actions, DPI and
footer geometry, scoped series-title choices, aspect-preserved cover fitting,
rating/count separation and text lifecycle. Existing SQLite/native-font skips,
absent Bookends checkout and four external artwork-source audit skips remain.
Physical Bigme rendering, touches, night mode, rotation and reading-return
checks remain open. Headless tests and schematic previews are not device
acceptance.
