# OrbitUI 0.1.0-alpha.13

Fixes the bookcase height after alpha.12: the bottom shelf now reserves space
for both pagination controls and the persistent bottom dock. **Preview release:
the corrected layout still needs a follow-up check on the Bigme B7 Pro.**

## Changes

- Calculates shelf row heights from the usable viewport, excluding the live
  bottom dock height instead of allocating the full screen to the shelves.
- Uses the shared visible pagination reserve, including negative top margins
  that move controls above the footer's outer box.
- Keeps all books cover-forward, native shelves, ornaments and cover proportions.
  Rows resize to fit; saved row counts and the normal hero size are retained.
- Existing icons, book data, reading progress, sync ownership and upstream
  baselines are unchanged. No settings migration is required.

## Updating

Open **Tools > OrbitUI > Uppdatera OrbitUI > Check for updates** with
**Include preview releases** enabled. Install alpha.13 and restart KOReader.
Alpha.12 and earlier alpha releases can update directly. Bootstrap API 1 and
the three bootstrap files are unchanged; previous-version rollback is retained.

For manual installation use `orbitui.koplugin.zip`, not the source-code archive.
Read [OTA and recovery](https://github.com/komadorirobin/orbitui.koplugin/blob/v0.1.0-alpha.13/docs/OTA.md)
before replacing an installation with an active OTA slot.

## Verification and limits

Seven new regression tests cover the 1264 x 1680 layout, changing dock and footer
heights, retained hero size, expanded layout and 432 viewport combinations.
Five reproduce the alpha.12 failure, including a two-row fixture overflowing
by exactly its 160px dock height. The corrected 40-test layout suite and full
Lua/LuaJIT suites are checked, together with 41 translation catalogs and the
sealed runtime inventory. The existing two native-SQLite and one opt-in
exhaustive geometry suite skips remain.

Native OTA checks use the published alpha.12 installer and KOReader's archive
and hash modules to test activation, restart, rollback and rejected incomplete
downloads. These checks do not replace physical-device testing. Check the
bottom shelf in portrait and landscape, after paging and after collapsing or
expanding the hero.
