# OrbitUI 0.1.0-alpha.6

Optional Material Symbols Rounded icons, including manga.
**Preview release: testing on the Bigme B7 Pro is still required.**

## Changes

- Adds 110 offline icons with a searchable picker and categories for reading,
  navigation, system functions and tools. Includes `manga` and `comic_bubble`.
- Provides a compact static weight-500 font (about 24 kB) and matching SVGs for
  image-only destinations. The original license and build provenance are bundled.
- Adds Material choices to Home/dock and system-icon settings, and to the
  Bookshelf icon library for shelf chips, start-menu icons and hero action cards.
- Keeps existing Nerd Font/custom image selections. Installing the update does
  not apply the new pack automatically, change layout or modify reading data.
- Stores named icon references and resolves packaged SVG paths against the
  active runtime so icon choices survive OTA version-directory changes.

To apply the pack, open **OrbitUI > Appearance > Home appearance > Icons >
Icon Packs > Material Symbols Rounded**. Individual system/quick-action icons
also offer **Material Symbols Rounded...**. Bookshelf's image-capable icon
picker has a **Material** category. Text-only token templates retain their
existing glyph choices. See [icon settings and integration details](https://github.com/komadorirobin/orbitui.koplugin/blob/v0.1.0-alpha.6/docs/ICONS.md).

Bookshelf and SimpleUI upstream baselines are unchanged from alpha.5. The
standalone plugins and their update channels are untouched. No new sync writer
or performance claim is introduced.

## Updating

Open **Tools > OrbitUI > Uppdatera OrbitUI > Check for updates** with
**Include preview releases** enabled. Install and restart KOReader.
Both embedded component update entries open the same OrbitUI updater.

For a first installation, download `orbitui.koplugin.zip`, not a source archive.
Follow [the migration guide](https://github.com/komadorirobin/orbitui.koplugin/blob/v0.1.0-alpha.6/docs/MIGRATION.md)
and keep standalone SimpleUI and Bookshelf disabled.

Bootstrap API 1 and previous-version rollback remain unchanged; see
[OTA and recovery](https://github.com/komadorirobin/orbitui.koplugin/blob/v0.1.0-alpha.6/docs/OTA.md).

## Verification and limits

Verification covers Lua and LuaJIT suites, 13 focused icon-integration tests,
asset checks, translation validation and the sealed runtime inventory. The
existing two native-SQLite and one opt-in exhaustive-geometry skips remain.
The static font was rendered at several sizes on the development machine and
its build reproduced byte-for-byte. Native archive/OTA checks cover extraction,
hashes, activation, rollback and rejection of incomplete or corrupt packages.

Headless tests and development previews are not device acceptance. Verify icon
sizes, night mode, mixed Material/Nerd/custom icons, menu tabs, screen rotation,
reset and persistence after restart/OTA on the reader. Existing icon choices
must remain unchanged until an icon or pack is explicitly selected.
