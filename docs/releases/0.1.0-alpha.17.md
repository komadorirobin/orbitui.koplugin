# OrbitUI 0.1.0-alpha.17

Adds author busts, colour Japanese ornaments, alphabetical series blocks and
session-stable ornament shuffling. **Preview release: the new rendering and
touch behavior still need testing on the Bigme B7 Pro.**

## Changes

- Adds the Authors pack: Strindberg, Lem, Dylan Thomas, Thomas Mann, Dostoevsky,
  Hamsun, Clarice Lispector, Musil and Kafka. Like Joyce and Woolf, each bust
  appears beside matching full author metadata, never beside unrelated books.
- Adds five colour Japan ornaments: pine bonsai, red maple bonsai, sleeping
  calico, maneki-neko and daruma. The original stock plants are disabled once,
  not deleted, and can be re-enabled. Custom same-name artwork is left alone.
- Shuffles ordinary ornaments once per KOReader startup, before the first shelf
  layout. Paging, book returns, profile switches and normal sleep/resume keep
  the order stable. Manual Shuffle all still works; manual moves last until
  the next shuffle or restart. Author busts retain their author matching.
- Interleaves grouped series with standalone books in alphabetically sorted
  bookcases, using series/folder name (first title as fallback) and author
  metadata for author sorts. Volumes stay together in ascending volume order.
  Grid/list, nonalphabetical and manual sorting remain unchanged.
- Installs new artwork additively without replacing user files or restoring
  deleted ornaments. Existing reading data, icon choices and sync ownership
  remain unchanged. Disabled packs and ornament frequency are respected.

The alpha.16 runtime did not contain these ornament and sorting changes despite
its notes. Alpha.17 includes them without replacing any earlier release assets.

## Updating

Open **Tools > OrbitUI > Uppdatera OrbitUI > Check for updates**, with
**Include preview releases** enabled. Install alpha.17 and restart KOReader.
Alpha.16 and earlier alpha versions can update directly; bootstrap API 1 and
the stable bootstrap files are unchanged. New packs install when the ornament
collection is first used, under **Wallpaper, ornaments and colours > Ornament
collection > Authors / Japan**.

For manual installation use `orbitui.koplugin.zip`, not GitHub's source archive.
Read [OTA and recovery](https://github.com/komadorirobin/orbitui.koplugin/blob/v0.1.0-alpha.17/docs/OTA.md).
Rollback keeps copied artwork and settings. Disable Authors on alpha.16 or
earlier, whose code does not know the new author bindings. The original stock
plants can be re-enabled in the ornament collection even after rollback.

## Verification and artwork

Release gates cover complete Lua/LuaJIT suites (240 OrbitUI cases, 46 Python
checks and both component suites), 41 translation catalogs, sealed inventory,
native OTA from the published alpha.16 installer, draft asset verification and
anonymous public OTA. Three known Bookshelf native-SQLite/opt-in geometry suite
skips remain. These checks do not constitute physical-device acceptance.

Artwork has separate licenses, attribution, provenance and exact prompts;
