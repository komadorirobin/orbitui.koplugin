# OrbitUI 0.1.0-alpha.12

All books now face cover-forward in the shelf/spines display, without replacing
the bookcase layout with a regular grid. **Preview release: shelf rendering,
page turns and touch targets still need testing on the Bigme B7 Pro.**

## Changes

- Every book displays its front cover, including existing Library and Manga
  shelves with older per-shelf orientation choices.
- Keeps native shelves, ornaments and cover proportions. Wider covers can mean
  fewer books per page; rendering and pagination use the same native layout.
- The shelf-style editor reports **Face out: All books** as a read-only row.
  Previous orientation preferences stay stored for code rollback.
- Ordinary cover grids, lists and Auto's folder behavior are unchanged, as are
  icons, book data, reading progress, sync ownership and upstream baselines.

## Updating

Open **Tools > OrbitUI > Uppdatera OrbitUI > Check for updates** with
**Include preview releases** enabled. Install alpha.12 and restart KOReader.
Alpha.11 and earlier alpha releases can update directly. Bootstrap API 1 and
the three bootstrap files are unchanged; previous-version rollback is retained.

For manual installation use `orbitui.koplugin.zip`, not the source-code archive.
Read [OTA and recovery](https://github.com/komadorirobin/orbitui.koplugin/blob/v0.1.0-alpha.12/docs/OTA.md)
before replacing an installation with an active OTA slot.

## Verification and limits

The Lua and LuaJIT suites include five focused all-cover shelf tests and the
existing component planning/pagination tests. All 41 translation catalogs and
the sealed runtime inventory are checked. The existing two native-SQLite and
one opt-in exhaustive geometry suite skips remain. Native OTA checks use the
published alpha.11 installer and KOReader's archive/hash modules to test
activation, restart, rollback and rejected incomplete downloads. These checks
do not replace physical-device testing.
