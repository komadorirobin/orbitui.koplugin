# OrbitUI 0.1.0-alpha.10

Solar and Tabler icons, plus a custom manga icon, selectable one icon at a time.
**Preview release: native touch, SVG appearance and e-ink contrast still need
testing on the Bigme B7 Pro.**

## Changes

- Adds curated offline **Solar Outline** (76), **Solar Line Duotone** (76) and
  **Tabler** (75) sources to the individual icon pickers. These are not the full
  upstream libraries or whole-pack presets. Nothing is replaced automatically.
- Adds **Manga (OrbitUI)** first in both Solar lists: a rounded book with
  hiragana on the cover, in monochrome and duotone. It is a credited adaptation
  of Solar and Tabler artwork. Tabler's `language-hiragana` is also included.
- Supports the same per-icon sources in the Home/dock/system-icon picker and
  Bookshelf's image-capable library, with search, categories and previews.
- Keeps all current selections and independent Material weights unchanged.
  Opening or cancelling a source does not save anything; selecting an icon
  changes only the edited button/action. Material's default remains 300.
- Uses local SVG geometry, never a new icon font. Solar keeps its original
  contours/opacity and Tabler its native stroke width. The combined Bookshelf
  picker labels the Material-only weight control explicitly.

Preview and controls: [Icon guide](https://github.com/komadorirobin/orbitui.koplugin/blob/v0.1.0-alpha.10/docs/ICONS.md).

Books, reading progress, synchronization, layouts and upstream baselines are
unchanged. No settings reset or recovery patch is required on a working install.

## Updating

Open **Tools > OrbitUI > Uppdatera OrbitUI > Check for updates** with
**Include preview releases** enabled. Install alpha.10 and restart KOReader.
You can update directly from alpha.9 or earlier alpha releases.

For manual installation use `orbitui.koplugin.zip`, not the source-code archive.
Read [OTA and recovery](https://github.com/komadorirobin/orbitui.koplugin/blob/v0.1.0-alpha.10/docs/OTA.md)
before replacing an installation with an active OTA slot. Bootstrap API 1,
the three bootstrap files and previous-version rollback remain unchanged.

## Verification and limits

Verification covers the full Lua and LuaJIT suites, 29 focused icon tests,
6 recovery tests, 39 Python tests, all 41 translation catalogs and the sealed
runtime inventory. The existing two native-SQLite and one opt-in exhaustive
geometry suite skips remain. Desktop SVG rendering covers all 227 new packaged
icons and both custom source SVGs. Native OTA checks use the published alpha.9
installer and KOReader's archive/hash modules to verify activation, restart,
rollback and rejected incomplete downloads.

Headless tests and desktop previews do not replace device testing. Select one
icon from each source, cancel without changes, mix sources, restart, and check
native menu/dock/chip sizing, dimming and duotone contrast on light/dark backgrounds.
