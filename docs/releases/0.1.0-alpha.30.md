# OrbitUI 0.1.0-alpha.30

Preview release: completed-series crash fix and refined slipcase rendering.

## Changes

- Fix a crash when displaying a series box whose books are all marked finished,
  both on returning to the shelf and after restarting KOReader. The native
  completed-mark compositor now receives an explicitly sized blank card.
- Preserve cover colours in the slipcase's procedural drawing instead of
  converting them to grey. Boards and rims use lighter cover-derived tones;
  the opening and title band retain darker shading for depth and contrast.
- Make the contact shadow follow the box's sloping lower-right edge instead
  of leaving a flat rectangular band on the shelf. Ordinary books retain
  their existing shadow geometry.

## Updating

Use **Uppdatera OrbitUI > Check for updates**, with preview releases enabled.
Install and restart KOReader. Manual installations use `orbitui.koplugin.zip`,
not GitHub's source archive.

The stable bootstrap and API 1 are unchanged; alpha.29 and earlier alpha
installations can update directly. Existing settings, books, reading history,
metadata and artwork are preserved. No upstream merge or settings migration
is included. Rolling back to alpha.29 also restores its completed-box crash.

## Validation Scope

Release checks cover Lua and LuaJIT integration/component suites, translations,
the runtime package, and OTA upgrade/rollback from the published alpha.29.
Two SQLite-dependent component suites require the device runtime and are
skipped locally. The completed-box crash was reproduced with KOReader's own
Widget/OverlapGroup implementations and passes after the fix. Twenty native
BlitBuffer checks cover greyscale/RGB, finished/unread and day/night drawing.
Regression tests also check colour-blitter selection and projected shadow
geometry. Visual and performance acceptance on the physical reader remains open.
