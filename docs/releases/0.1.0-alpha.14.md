# OrbitUI 0.1.0-alpha.14

Adds the James Joyce and Virginia Woolf author busts, automatically installed
with OrbitUI and placed next to the correct authors' books. **Preview release:
on-device rendering and touch behavior still need testing on the Bigme B7 Pro.**

## Changes

- Bundles the two transparent PNG ornaments as the **Modernists** pack.
- Matches full author metadata, including `Joyce, James` and `Woolf, Virginia`.
  A bust appears before its author's book/run and again when a run continues
  on a new page. It never appears at random beside an unrelated book or on
  an empty shelf. Missing metadata is not guessed from titles or filenames.
- Reserves room in the native shelf planner and keeps book/bust pairs together
  during balancing. Narrow rows shrink or omit a bust instead of overlapping.
- Respects disabled ornaments/packs and the shelf's **None** setting. Other
  ornaments retain their native frequency pattern. Enabled author busts are
  placed at matching runs independently of that pattern.
- Installs once without replacing user files or restoring deleted ornaments.
  Existing reading data, icons, sync ownership and upstream baselines stay intact.
- Keeps alpha.13's dock-aware shelf height and cover-forward books.

## Updating and controls

Open **Tools > OrbitUI > Uppdatera OrbitUI > Check for updates**, with
**Include preview releases** enabled. Install alpha.14 and restart KOReader.
Alpha.13 and earlier alpha versions can update directly; bootstrap API 1 is
unchanged. The pack is installed when the shelf/ornament collection first opens.

Find it under **Wallpaper, ornaments and colours > Ornament collection > Modernists**.
Tap a bust on a shelf to zoom; long-press for size/height controls. A previously
installed `Modernists-Preview` trial copy is also author-matched, without placing
duplicate busts when both packs are enabled.

For manual installation use `orbitui.koplugin.zip`, not the source-code archive.
Read [OTA and recovery](https://github.com/komadorirobin/orbitui.koplugin/blob/v0.1.0-alpha.14/docs/OTA.md).
Rollback preserves installed ornament files. Older versions lack author matching;
disable the pack there if you do not want their ordinary random placement.
