# OrbitUI 0.1.0-alpha.53: standalone configuration test alpha

This prerelease prepares OrbitUI for people without a BookOrbit-specific setup.
It is deliberately another **test alpha**, not the first beta: the new setup
flow and appearance choices still need physical-reader acceptance.

## What changes

- **Library sections:** choose names, icons, folders, order and shelves instead
  of requiring the original Fiction/Manga split. Existing sections retain their
  identity and settings; changing paths does not move books.
- **Reading dashboard:** show, hide and reorder cards; choose local TBR, new
  books, history, collections, saved shelves or cached BookOrbit for book rows.
  Reading goals can use local data or optional Hardcover. Each screen keeps its
  own configuration, headings and independent book-row pagination.
- **Setup guide:** review folders, launch screen, bottom-bar buttons and shelf
  preset before applying. Fresh installs are offered the guide; upgrades keep
  their layout and can open it from **OrbitUI settings > Setup guide**. Cancel
  leaves the draft unapplied. Optional integrations are explained without
  requiring accounts, connections or network requests.
- **Shelf presets:** **Shelf settings** follows native per-shelf choices and
  installs no extra artwork; **Classic OrbitUI** keeps the established face-out
  shelves, series boxes and ornament behavior; **Minimal bookshelf** hides boxes
  and ornaments. Existing OrbitUI installations retain Classic, while new
  installations start neutral. Presets do not erase native shelf preferences,
  Home pages, wallpapers, icons, reading data or credentials.

Bookshelf 5.5.4 (`982375a7`) and SimpleUI 2.7.5 (`7eb80f9e`) remain the reviewed
baselines. No upstream merge or new artwork is included. Existing book binding,
cover geometry, series ratings, targeted ornaments and paging remain available.

## Update and rollback

Install through **Uppdatera OrbitUI > Check for updates** with preview releases
enabled, then restart KOReader. Alpha.48 or newer can install directly; older
installers require the small alpha.48 bridge first because this package exceeds
64 MiB. Keep a separate current backup of KOReader settings and the working
installation. Never enable standalone SimpleUI/Bookshelf alongside OrbitUI.

Rollback restores code, not preferences. Alpha.52 ignores the new section
registry, dashboard configuration and presets. Setup-guide changes to shared
launch/dock preferences remain, and new section buttons need alpha.53. Keep the
existing bar for the initial upgrade test; restore only affected UI preferences
if needed, never older reading progress. Switching away from Classic does not
delete artwork already installed. See [migration](../MIGRATION.md) and
[OTA recovery](../OTA.md).

## Reader checklist before beta

1. Upgrade the existing setup and restart. Confirm Home, Library/Manga, custom
   pages, icons, backgrounds, reading progress and integrations remain intact.
2. Open **OrbitUI settings > Setup guide** manually. Test opening and cancelling,
   then review/apply only intended changes. Restart and check navigation.
3. Under **Appearance > Shelf preset**, try all three choices, switch back to
   Classic, open/leave series, page and restart. Check both Library and Manga.
4. Change dashboard card visibility/order and each book row's source; test swipe
   and arrow paging, offline operation and rotation without losing other pages.
5. In an isolated fresh KOReader settings copy, verify the automatic guide,
   folder selection, Skip/Cancel/Apply, reader-first startup and operation without
   BookOrbit/Hardcover/MyAnimeList. Do not erase the working setup to test this.

Automated Lua/LuaJIT, packaging and native OTA/rollback checks are separate from
this physical-device acceptance. Report any failure before approving beta.
