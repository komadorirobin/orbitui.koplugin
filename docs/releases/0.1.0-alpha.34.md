# OrbitUI 0.1.0-alpha.34

Preview release: independent cover text for each shelf, including physical
bookcases.

## Changes

- Long-press a shelf chip and choose **Cover text** (**Omslagstext** in Swedish).
  Select Title, Author, Series, Custom text or None. The former global book-text
  control is removed; the separate group-text setting is unchanged.
- Save each shelf's choice independently, including identically named Library
  and Manga chips and native nested shelves. Folder and series drills inherit
  the current chip's choice. Untouched shelves keep their existing appearance.
- Apply the choice to regular/full-screen cover grids and physical bookcases.
  Grids show text below covers; physical shelves show a single-line dark band
  inside each cover, clear of its progress bar. Long text truncates to fit and
  very small covers omit a band that cannot fit safely.
- Retain Custom text's token picker, bold, uppercase and live preview, with
  Save/Cancel scoped to the original shelf. Delayed previews cannot leak into
  another chip or reappear after cancellation.
- Preserve series boxes' own labels and read counters, completed-book fading,
  status marks, opening effects, ornament placement, cover sizing and pagination.
  Labels also work with light metadata before a full book record is available.

## Updating

Use **Uppdatera OrbitUI > Check for updates**, with preview releases enabled.
Install and restart KOReader. Then long-press the desired chip and choose
**Omslagstext > Titel** to enable titles on that shelf.

Manual installations use `orbitui.koplugin.zip`, not GitHub's source archive.
The stable bootstrap and API 1 are unchanged; alpha.33 and earlier alpha
installations can update directly. No books, reading history, sync data,
artwork, upstream baselines or external plugins are changed.

Keep a settings backup. Upgrading from before alpha.33 also includes Bookshelf
5.4's theme-storage migration; code rollback does not reverse that migration.
The new per-shelf text preferences survive rollback, but earlier runtimes ignore
them and use their previous global text setting.

## Validation Scope

Release gates cover full Lua/LuaJIT integration and component suites,
translations, a sealed runtime ZIP and native OTA upgrade/rollback from the
published alpha.33, including anonymous discovery and download.
Fourteen focused regressions cover scoped persistence, custom preview/save/cancel,
grid label budgets, light metadata and bounded physical-card painting/disposal.
Existing native SQLite/font dependency skips and four external artwork-source
audit skips remain; artwork is unchanged.

Physical-reader appearance and interaction still need validation, especially
font sizing, colour/night mode, progress bars, finished covers and opening
effects. Headless tests do not establish device-level rendering or OTA behavior.
