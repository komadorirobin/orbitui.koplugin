# OrbitUI 0.1.0-alpha.8

Fixes the crash when opening **Material Symbols Rounded...** to change one icon.
**Preview release: the corrected picker still needs testing on the Bigme B7 Pro.**

## Changes

- Fixes a numeric loop variable shadowing the translation function while the
  Material category list is built. The failure was reproduced before any SVG
  was rendered; it is separate from the earlier alpha.6 startup report.
- Expands regression coverage to construct and refresh the real shared modal
  over native widget stubs, rather than replacing it with a passive placeholder.
  Tests cover English/Swedish labels, both orientations, touch-only/directional-key
  configurations, categories, search, pagination, empty results, selection and cancel.
- Retains the 110 offline SVG icons and individual selection introduced in
  alpha.7. Opening or cancelling the picker changes nothing; selecting changes
  only the chosen icon. No whole-pack replacement is reintroduced.

Existing icon choices, layout, books, progress, sync settings and upstream
baselines are unchanged. No reset or recovery patch is required on a working
installation.

## Updating

Open **Tools > OrbitUI > Uppdatera OrbitUI > Check for updates** with
**Include preview releases** enabled. Install alpha.8 and restart KOReader.
You can update directly from alpha.5, alpha.6 or alpha.7.

For manual installation use `orbitui.koplugin.zip`, not the source-code archive.
Read [OTA and recovery](https://github.com/komadorirobin/orbitui.koplugin/blob/v0.1.0-alpha.8/docs/OTA.md)
before replacing an installation with an active OTA slot. Bootstrap API 1,
the three bootstrap files and previous-version rollback remain unchanged.

## Verification and limits

Verification covers the full Lua and LuaJIT suites, 18 focused icon tests,
6 recovery tests, all 41 translation catalogs and the sealed runtime package.
The existing two native-SQLite and one opt-in exhaustive-geometry suite skips
remain. Packaged OTA checks use the published alpha.7 installer with KOReader's
native archive/hash modules to verify activation, restart, rollback and rejected
incomplete downloads.

Headless tests do not verify native SVG painting, touch behavior, keyboard or
e-ink contrast. On the device, test opening Material for one icon, browsing and
searching, cancelling without changes, selecting a manga icon, and restarting.
