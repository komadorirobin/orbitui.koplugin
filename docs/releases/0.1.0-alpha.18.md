# OrbitUI 0.1.0-alpha.18

Independent Bento margins, less crowded shelf ornaments and the reviewed
Bookshelf/SimpleUI upstream merge. **Preview release: the latest layout changes
still need testing on the Bigme B7 Pro.**

## Changes

- Fixes Top Margin for individual Bento modules, including New Books in the
  right-hand column and modules stacked below others. Labels and contents move
  together. Columns now align to the row's top edge instead of vertically
  centring against their neighbours. Existing saved margins are retained;
  layouts that relied on centring may need individual margins adjusted.
- Limits ordinary ornaments to one per physical shelf row. Several author
  busts can share a row beside their matching books; those rows receive no
  additional ordinary decoration. Bust/book pairs carry to the next row when
  necessary. Disabled packs, frequency, author matching and session-stable
  shuffling remain respected.
- Includes the reviewed SimpleUI 2.7.5 changes: safer Android zlib loading,
  screen-bound pagination callbacks and immediate streak refresh. Preserves
  OrbitUI's cache protections and fresh label widgets.
- Includes Bookshelf upstream through `74b825bb` and SimpleUI through `19874b3b`.
  The Bookshelf changes in this merge improve portable tests and enable the
  exhaustive row-budget check by default; no unmeasured speedup is claimed.

No saved settings are reset. Reading data, BookOrbit sync ownership, icons,
artwork, cover-facing shelves and dock clearance remain unchanged.

## Updating

Open **Tools > OrbitUI > Uppdatera OrbitUI > Check for updates**, with
**Include preview releases** enabled. Install alpha.18 and restart KOReader.
Alpha.17 and earlier alpha releases can update directly; bootstrap API 1 and
the stable bootstrap files are unchanged.

For manual installation use `orbitui.koplugin.zip`, not GitHub's source archive.
See [OTA and recovery](https://github.com/komadorirobin/orbitui.koplugin/blob/v0.1.0-alpha.18/docs/OTA.md).
Rollback changes code only, not settings, reading data or installed artwork.

## Verification

Release gates cover complete Lua/LuaJIT suites (275 OrbitUI cases, 46 Python
checks, 351 Bookshelf suites and all 13 SimpleUI test files), 41 translation
catalogs, sealed package inventory, native OTA from the published alpha.17
installer, draft-asset verification and anonymous public OTA. Two Bookshelf
native-SQLite suites remain explicit skips. Headless checks are not physical
device acceptance; verify module margins and rows with several authors on Bigme.

Artwork retains its separate licenses and attribution, including the
