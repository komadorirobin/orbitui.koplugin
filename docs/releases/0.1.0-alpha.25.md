# OrbitUI 0.1.0-alpha.25

Adjustable bookcase covers and responsive bottom-bar margins.
**Preview release: appearance and margin changes still need device testing.**

## Changes

- Physical bookshelf covers can be sized from 50% to 150% in 10% steps.
  The default, 100%, preserves the existing layout. Long-press a Library/Manga
  chip, choose **Redigera hylla**, then **Omslagsstorlek**. For editable custom
  chips, open **Shelf style** inside their editor. The setting is per chip.
- Covers keep their proportions and stop growing at the available shelf height.
  Wider covers repaginate instead of overlapping books or ornaments. The hero,
  row count, ornament sizes and pagination/dock space are unchanged. Back-page
  boundaries are refreshed after resizing without moving the current book.
- Bottom-bar margin changes now rebuild the visible Library/Manga dock. A warm,
  hidden shelf updates on return rather than appearing over Home or the reader.
  Home also recalculates its body/footer layout after the available height changes.
  Ordinary icon/status updates do not force a full bookshelf rebuild.
- Existing margin settings, artwork, author matching, reading data and sync
  configuration are preserved. No upstream merge or new artwork is included.

## Updating

Open **Tools > OrbitUI > Uppdatera OrbitUI > Check for updates**, with
**Include preview releases** enabled. Install alpha.25 and restart KOReader.
Alpha.24 and earlier alpha releases can update directly; bootstrap/API 1 is
unchanged. Use **orbitui.koplugin.zip**, not the source-code archive.

Code rollback preserves settings and reading data. Earlier versions ignore the
new cover-size preference. Allow roughly 250 MiB free in addition to installed
versions.

## Verification

Release gates include complete Lua and LuaJIT suites, translation validation,
the sealed runtime ZIP, downloaded draft-asset checksums, CI, native OTA from
the actual alpha.24 installer, and anonymous public OTA checks. Native-SQLite
and font-dependent cases retain their documented environment skips.

These headless checks do not replace a device test. Check larger covers and
page turns in Library/Manga, then bottom-bar margin changes in both Home and
Library/Manga, including returning to a previously opened shelf.

[OTA and recovery](https://github.com/komadorirobin/orbitui.koplugin/blob/v0.1.0-alpha.25/docs/OTA.md).
