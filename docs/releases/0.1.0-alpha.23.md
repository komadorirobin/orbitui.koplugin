# OrbitUI 0.1.0-alpha.23

Refined photographic Hemingway and Mann shelf ornaments.
**Preview release: physical Bigme appearance and migration acceptance still
need device testing.**

## Changes

- Hemingway keeps the real broad-shouldered Cojimar sculpture, with a level
  lower crop through its photographed stone support. Removing unused transparent
  headroom makes the visible bust about 67% taller at standard size, without
  stretching the photograph or extending its image box above the shelf row.
- Mann retains Seitz's bronze portrait and compact mounting block; the wide
  protruding plate is excluded and the default scale is adjusted to fit.
- Both images preserve original photograph pixels and colours. No generated
  faces, anatomy or bases. Author matching, Swedish biographies, zoom and all
  other author images are unchanged.
- Independent, resumable migrations replace only exact known default images.
  Custom images, captions, placements, disabled pieces, native overrides, linked
  paths and deleted files are preserved. Completed alpha.22 markers do not
  block the refinements. Updated credits are included with the images.

No upstream merge, reading-data change or synchronization change. Bookshelf
remains at 5.3.1 through `74b825bb`, SimpleUI at 2.7.5 through `b58dfefb`.
Photograph licenses and sculpture-rights notes remain separate; the retired
AI-assisted Mann bitmap is not included in the package or published ancestry.

## Updating

Open **Tools > OrbitUI > Uppdatera OrbitUI > Check for updates**, with
**Include preview releases** enabled. Install alpha.23 and restart KOReader.
Alpha.22 and earlier alpha releases can update directly with bootstrap/API 1
unchanged. Allow roughly 250 MiB free in addition to installed versions.

Use **orbitui.koplugin.zip**, not GitHub's source-code archive. No separate
ornament download is required. Avoid manually overwriting customized ornament
folders. Code rollback retains copied artwork and metadata; keep backups for
asset-level rollback.

## Verification

Release gates cover 87 Python checks, 389 OrbitUI cases on Lua and LuaJIT,
351 passing Bookshelf suites, all 13 SimpleUI test files and 41 translation
catalogs. Two native-SQLite suites and existing font-dependent cases remain
explicit skips. Original-photo/museum pixel audits run locally with source
caches; CI skips the four cache-dependent checks.

The release process verifies the sealed runtime, downloaded draft assets,
native OTA from the actual alpha.22 installer, CI and anonymous public OTA.
These headless checks do not replace a device test of silhouettes, base
alignment, author adjacency, touch/zoom and preserved custom ornament settings.
