# OrbitUI 0.1.0-alpha.29

Preview release: open series slipcases and series reading status.

## Changes

- Series boxes on physical bookshelves now resemble open slipcases, with a
  recessed opening, thin edges and up to six shaded, rounded book bindings.
  Binding colours use the books' cached cover samples, not fabricated spine
  artwork. The first volume remains the main cover.
- Width increases with the number of volumes, capped at six illustrated
  bindings. Larger series retain their full membership and exact counts.
  Pagination accounts for the wider boxes; height and dock clearance do not
  increase.
- The series name appears on a slim dark band instead of a pale label.
- A top-right read/total badge, such as 12/16, replaces the separate volume
  count line and matches the manga stacks' reading-status rules.
- When every member is finished, the box receives the ordinary completed-book
  mark and fade according to existing preferences. The name and count remain
  clear. Marking any member unfinished removes this treatment on rebuild.

## Updating

Use **Uppdatera OrbitUI > Check for updates**, with preview releases enabled.
Install and restart KOReader. Manual installations use `orbitui.koplugin.zip`,
not GitHub's source archive.

The stable bootstrap and API 1 are unchanged; alpha.28 and earlier alpha
installations can update directly. Existing settings, book files, reading
history, metadata and artwork are preserved. No upstream merge or settings
migration is included. Restoring the previous OrbitUI version restores its
series presentation without changing reading data.

## Validation Scope

Release checks cover Lua and LuaJIT integration/component suites, translations,
the runtime package, and OTA upgrade/rollback from the published alpha.28.
Focused regression tests cover scoped read counts, completed-status settings,
palette changes, bounded colour sampling, narrow layouts, perspective and
fade containment. Headless previews use illustrative covers and font metrics.
Visual and performance acceptance on the physical reader remains open.
