# OrbitUI 0.1.0-alpha.43

Preview release with larger series artwork and selectable book bindings.

## Changes

- Series slipcases devote more height to the picture without stretching or
  cropping the cover. Exposed book heads are more compact, and the read/total
  label sits there rather than in a separate picture band. The minimum box
  width increases to 85% of a normal cover, within the existing width/space cap.
- Choose **Book binding** (Swedish: **Bokbindning**) by long-pressing a shelf
  chip: **Hardcover**, **Paperback** or **Manga / tankobon**. Paperback has thin,
  flush boards and subtler page lines; manga has a lighter jacket and dark
  lettering. Untouched shelves keep Hardcover.
- Long-press a series box for the same choice per series. A series override
  takes precedence across shelves and also applies inside the series. Choose
  **Follow shelf** to remove just that override.
  These are visual choices, not changes to book metadata or reading progress.
- Automatic series artwork now uses the first book's hydrated cover metadata,
  fixing placeholders for books whose covers are available. Custom-image
  selection and missing-image fallback remain supported.
- The image picker uses plain, filename-sorted entries instead of scanning
  subfolder counts or book metadata. Missing start paths fall back to an
  existing directory. Native navigation and long-press confirmation remain.
  This removes expensive synchronous work; the reported device lock-up still
  needs confirmation after updating.

Upstream pins remain Bookshelf 5.5.2
`c7a9db2ca1c21ef6a38715e74306fe7f514ba807` and SimpleUI 2.7.5
`7eb80f9e570e6351c55f501f91e1a29c1442b756`. No artwork changes or new upstream
imports are included. Existing Library/Manga profiles, cover sizing/labels, ornaments,
custom icons and BookOrbit sync ownership are retained. The older box design
remains archived locally, not an in-app switch.

## Updating

Use **Uppdatera OrbitUI > Check for updates**, with preview releases enabled.
Install and restart KOReader. Alpha.42 and earlier alpha installations use the
same stable bootstrap/API 1. For manual installation choose
`orbitui.koplugin.zip`, not GitHub's source archive.

Keep the previous installation and settings backup. Code rollback leaves
reading progress and settings intact; older code ignores the new binding
choices. Earlier appearance, theme-storage, grouped-order, ledger and
module-edit rollback caveats still apply.

## Validation Scope

Release gates cover sequential full Lua/LuaJIT integration/component suites,
all 43 translation catalogues, sealed runtime and outgoing-history/artwork
audits, the published alpha.42 installer's upgrade/rollback, both CI jobs,
downloaded draft hashes and anonymous public discovery/download/install.

Existing SQLite/native-font skips, absent Bookends parity checkout and four
external artwork-source audit skips remain. Focused tests cover scope and
inheritance, live cache refresh, cover aspect, completion, metadata hydration,
binding colours/text contrast and native picker work. Physical Bigme checks
remain open: visual appearance in colour/night mode, small/large series,
opening animation, and image-picker responsiveness. Headless tests and the
shape-only preview are not device acceptance.
