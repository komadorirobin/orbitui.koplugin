# OrbitUI 0.1.0-alpha.35

Preview release: place book text above the cover, independently for each shelf.

## Changes

- Long-press a shelf chip and choose **Cover text > Placement > Above the cover**
  (**Omslagstext > Placering > Ovanför omslaget** in Swedish).
- The choice works in regular and full-screen cover grids and the physical
  bookcase. Library, Manga and nested shelves retain independent choices;
  folders and series opened within a chip inherit its placement.
- **Bottom (default)** preserves the previous below-cover grid text or in-cover
  bookcase band. Placement does not change the content or custom template, and
  does not enable text when None is selected.
- Grid slots reuse their existing label space. Physical labels sit above the
  book's page block, using headroom first. When necessary, the cover shrinks
  proportionally, with matching page-block, feet and shadow widths. The book
  stays on the shelf and the row budget and pagination remain unchanged.
- Long labels truncate; very small rows omit labels that cannot safely fit.
  Above-cover text can be tapped, held or double-tapped like the book itself,
  and follows finished/on-hold fading. Status marks and the real opening target
  are preserved. Series boxes, group labels and ornaments are unchanged.

## Updating

Use **Uppdatera OrbitUI > Check for updates**, with preview releases enabled.
Install and restart KOReader. Long-press the desired chip, select a text type
under **Omslagstext**, then select its **Placering**. Existing shelves do not
change automatically.

For manual installation, use `orbitui.koplugin.zip`, not the source archive.
The stable bootstrap and API 1 are unchanged; alpha.34 and earlier alpha
installations can update directly. No books, reading history, artwork, sync
settings, upstream baselines or external plugins are changed.

Keep a settings backup. Upgrades from before alpha.33 also include Bookshelf
5.4's theme-storage migration; code rollback does not reverse it. The new
placement preference survives rollback, but older runtimes ignore it.

## Validation Scope

Release gates cover full Lua/LuaJIT integration and component suites,
translations, the sealed runtime ZIP, and upgrade/rollback from the published
alpha.34, including anonymous release discovery and download.
Twenty focused cover-label regressions cover scoped preferences, custom text,
placement menus, native grid/physical row geometry, DPI/font-size bounds,
proportional sizing, label gestures, fading and disposal.

Existing native SQLite/font dependency skips and four external artwork-source
audit skips remain. Artwork is unchanged. Physical-reader appearance and
interaction still need checking, especially fonts, night mode and opening
effects. Headless checks are not device-level rendering or OTA tests.
