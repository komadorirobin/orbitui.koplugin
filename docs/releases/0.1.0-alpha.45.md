# OrbitUI 0.1.0-alpha.45

Preview release with Kanzenban bindings and MAL star ratings on series boxes.

## Changes

- **Kanzenban / large format** replaces Tankobon. It uses Paperback's
  cover-derived colours and thin soft boards, about 12% taller where shelf
  space permits. Cover proportions and page-derived spine thickness are kept.
- Choose the binding by long-pressing a shelf chip > **Book binding**, or
  long-press a series box to override it for that series. Existing Tankobon
  selections display as Paperback without rewriting saved preferences;
  Kanzenban must be selected explicitly. Paperback and Hardcover are unchanged.
  Labels use Swedish when selected in KOReader and English otherwise.
- Linked series boxes show the cached MyAnimeList community rating as a small
  **star + score** sticker, for example **★8.72**, at the cover's upper-left.
  It uses the same provider, typography and colours as folder cards, not a
  personal rating or a new network request. No MAL plugin update is needed.
- The cover keeps its size and proportions. Read/total and **+N** remain in
  the exposed book heads, with the series name below the cover. Unrated series
  have no sticker; exceptionally small covers omit it rather than clip text.
  Cached rating changes and unlinking are reflected when the box repaints.

Alpha.44's natural member widths, partial box interiors and complete series
navigation remain. Upstream pins stay at Bookshelf 5.5.2
`c7a9db2ca1c21ef6a38715e74306fe7f514ba807` and SimpleUI 2.7.5
`7eb80f9e570e6351c55f501f91e1a29c1442b756`. No upstream import, artwork change,
settings migration or reading-data change is included. Existing profiles,
ornaments, icons, sorting and BookOrbit sync ownership are retained.

## Updating

Use **Uppdatera OrbitUI > Check for updates**, with preview releases enabled.
Install and restart KOReader. Alpha.44 and earlier alpha installations use the
same stable bootstrap/API 1. For manual installation choose
`orbitui.koplugin.zip`, not GitHub's source archive.

Keep the previous installation and settings backup. Code rollback preserves
reading data and preferences; older code does not implement Kanzenban or the
new box rating. Earlier appearance, theme-storage, grouped-order, ledger and
module-edit rollback caveats still apply.

## Validation Scope

Release gates cover sequential full Lua/LuaJIT integration/component suites,
all 43 translation catalogues, sealed runtime and outgoing-history/artwork
audits, the published alpha.44 installer's upgrade/rollback, both CI jobs,
downloaded draft hashes and anonymous public discovery/download/install.

Focused coverage includes binding scope and legacy choices, bounded height,
cover proportions, natural spine widths, actual MAL provider lookup with
fixture data, missing/updated/unlinked ratings, completed series, DPI/size,
day/night colours and separation from existing labels. Existing SQLite/native
font skips, absent Bookends checkout and four external artwork-source audit
skips remain. Physical Bigme checks of height, rating placement, colour/night
legibility and interaction remain open; headless tests are not device acceptance.
