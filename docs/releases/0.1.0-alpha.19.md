# OrbitUI 0.1.0-alpha.19

Ukiyo-e Gallery: 27 traditional Japanese woodblock prints for your shelves.
**Preview release: physical Bigme display, touch and theme acceptance remain
outstanding.**

## Changes

- Adds 27 actual CC0 museum prints by Hokusai, Hiroshige, Utamaro, Sharaku and
  Kuniyoshi, independently selected from the Cleveland Museum of Art and The
  Met. Original images are proportionally scaled, never cropped or recoloured,
  and mounted in our own frames. No paid Ko-fi pack assets were used.
- Tap a framed print for the native enlarged view and scrollable information:
  title, artist, date, a short Swedish note, museum credit and source URL.
  Everything is bundled for offline use, including per-work rights evidence.
- Adds an optional washi wallpaper and Hinoki-style shelf plank. Only these
  material textures are AI-generated; the museum prints are not.
- Installs the pack once without overwriting existing user files, resetting
  settings or activating a theme. Paintings respect session-stable shuffling,
  the one-ordinary-ornament-per-row limit and matching author-bust priority.

Retains alpha.18's Bento margin fixes and multiple matching author busts per
row. Bookshelf remains at 5.3.1 through `74b825bb`, SimpleUI at 2.7.5 through
`19874b3b`. No new upstream merge, reading-data change or sync change.

## Updating And Using The Gallery

Open **Tools > OrbitUI > Uppdatera OrbitUI > Check for updates**, with
**Include preview releases** enabled. Install alpha.19 and restart KOReader.
Alpha.18 and earlier alpha releases can update directly; bootstrap API 1 and
the stable bootstrap files are unchanged. Allow roughly 250 MiB free space
in addition to existing installations.

**Ornament collection > Ukiyo-e Gallery** controls individual prints.
**Shelf theme > Ukiyo-e Gallery** selects the complete coordinated theme.
Native full-theme selection replaces the active ornament packs. To keep author
busts and other ornaments mixed in, select the wallpaper and **Shelf plank >
Hinoki** individually rather than selecting the full theme.

The runtime `orbitui.koplugin.zip` already contains the gallery. The optional
`orbitui-ukiyoe-gallery.zip` is only for manual ornament installation: extract
its `Ukiyo-e Gallery` folder into `koreader/settings/bookshelf/ornaments/`, not
the plugins folder. OTA users do not need this separate ZIP.

For manual plugin installation use `orbitui.koplugin.zip`, not GitHub's source
archive. See [OTA and recovery](https://github.com/komadorirobin/orbitui.koplugin/blob/v0.1.0-alpha.19/docs/OTA.md).
Rollback changes code only, not settings, reading data or installed artwork.

## Verification

Release gates cover complete Lua/LuaJIT suites (284 OrbitUI cases, 56 Python
checks, 351 Bookshelf suites and all 13 SimpleUI test files), 41 translation
catalogs, all 27 original-image pixel comparisons, sealed package inventory,
native OTA from the published alpha.18 installer, draft-asset byte verification,
both CI jobs and anonymous public OTA. Two Bookshelf native-SQLite suites remain
explicit skips. Colour/grayscale proof sheets and headless checks are not
physical-device acceptance; check frame placement, tap-to-enlarge, information
scrolling and theme controls on the Bigme.

The new gallery carries its own CC0 notices and provenance. Existing artwork
keeps its separate licenses, including the non-commercial Woolf and Dostoevsky
adaptations. See [ornament notices](https://github.com/komadorirobin/orbitui.koplugin/blob/v0.1.0-alpha.19/docs/ORNAMENTS.md).
