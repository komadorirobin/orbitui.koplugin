# OrbitUI 0.1.0-beta.3

Bookshelf 5.5.5, with OrbitUI's integrated Home and library experience retained.

OrbitUI includes and adapts **Bookshelf by AndyHazz** and **SimpleUI by
doctorhetfield-cmd**, with their contributors' work. This is an independent
combined plugin, not an official release by either upstream project.

## Changes since Beta 2

- Updated Bookshelf to **5.5.5**, plus the subsequent fix for a Shelf size
  statistics card that wraps into two columns. Configurable shelf tabs,
  nested shelves, themes and series boxes remain available.
- Optional star ratings in the corner of book covers. Choose **Settings >
  Cover display > Favorite icon or star rating > Stars (rating)**.
- Optional cached Hardcover ratings for books without your own rating,
  consistently used for cover stars, rating sorts and the Ratings shelf.
  Enable **Hardcover enrichment > Use Hardcover rating if no user rating**.
  No background rating fetch or change to your personal ratings is introduced.
- New assignable **Bookshelf: refresh the library** action.
- Home/folder shelves sorted by reading activity update their ordering after
  closing a book. Back and Folder up stop at the base shelf instead of escaping
  above the library root.
- Page totals and current-page labels respect KOReader's disabled stable-page
  setting while retaining OrbitUI's current rendered-page-count handling.
- Tall top panels give their cover more room. Clearing the cover cache also
  refreshes sampled spine colours, retaining reading status and page counts.

SimpleUI remains **2.7.5**. OrbitUI's library sections, Home dashboard, book
bindings, aspect-preserving series covers, MAL box badges and optional ornament
add-ons are retained. No artwork or reading-data migration is included.

The installation guide now points Storefront users to **26.10.20 or newer**,
which includes the upstream fix for installing plugins with embedded components.
OrbitUI's own updater remains the recommended upgrade path.

## Install or update

Existing users: open **Tools > OrbitUI > Uppdatera OrbitUI**, enable preview
releases, check for updates and restart KOReader. Beta 2 can update directly;
the bootstrap and API 1 are unchanged. Older OrbitUI versions can use internal
OTA directly too; external overwrites of an active old OTA slot still require
the precautions in the recovery guide.

For a first installation, download **orbitui.koplugin.zip**, not GitHub's
source archive. **OrbitUI replaces standalone SimpleUI and Bookshelf.** Disable
both and restart before installation; retain their files and settings for backup.
See the [installation guide](https://github.com/komadorirobin/orbitui.koplugin/blob/v0.1.0-beta.3/README.md#installation).

## Verification and limitations

The release gate includes full Lua/LuaJIT regression suites, translation checks,
sealed ZIP/inventory validation and native archive/HTTPS OTA upgrade, restart
and rollback checks from Beta 2. These are headless tests, not physical reader
acceptance. Please report device-specific layout or gesture issues.

Bookshelf revision: `065f25c06d9a8e0607f29cbe632f4b3d44a8bd37`, including release
`v5.5.5` at `2d26fd7f96ee1cc5caccf3960bd70076ca7a763e` and PR #544.
SimpleUI revision: `7eb80f9e570e6351c55f501f91e1a29c1442b756`.
Settings, ornaments and reading progress are retained. Code rollback does not
restore old reading data. Keep a separate backup; see
[OTA recovery](https://github.com/komadorirobin/orbitui.koplugin/blob/v0.1.0-beta.3/docs/OTA.md).
