# OrbitUI 0.1.0-beta.4

SimpleUI's latest dialogs and Tabbed Grid fix, alongside Bookshelf 5.5.5.

OrbitUI includes and adapts **Bookshelf by AndyHazz** and **SimpleUI by
doctorhetfield-cmd**, with their contributors' work. This is an independent
combined plugin, not an official release by either upstream project.

## Changes since Beta 3

- Updated embedded SimpleUI through `dd541fc2` (upstream still identifies as
  **2.7.5**): redesigned action/selection dialogs, book and folder actions,
  configuration controls and shared window-hook handling.
- **Tabbed Grid** was already available in OrbitUI. Its visible frame now
  follows the active tab's content height; space reserved for taller tabs sits
  outside the frame, so switching tabs does not move the modules below it.
- Retained OrbitUI's Home/library navigation, shared book-information panel,
  custom icon sources, current settings and cache fast paths. Navigation guards
  are adapted to the new window hooks, including safe third-party teardown.
- Bookshelf remains **5.5.5**, including PR #544's Shelf size fix. Shelf tabs,
  series boxes, binding options, ratings and optional ornament add-ons remain.
- Updated the SimpleUI credit to its new **GPL-3.0** license. The original MIT
  notice is retained for previously imported code. OrbitUI remains AGPL-3.0.

No new artwork, bootstrap changes or reading-data migrations are included.

## Install or update

Existing users: use **Tools > OrbitUI > Uppdatera OrbitUI**, enable preview
releases, check for updates and restart KOReader. Beta 3 can update directly;
the bootstrap and API 1 are unchanged.

For a first installation, download **orbitui.koplugin.zip**, not GitHub's source
archive. **OrbitUI replaces standalone SimpleUI and Bookshelf.** Disable both
and restart before installation; keep their files and settings for backup.
See the [installation guide](https://github.com/komadorirobin/orbitui.koplugin/blob/v0.1.0-beta.4/README.md#installation).

## Verification and limitations

The release gate includes full Lua/LuaJIT regression suites, translation checks,
sealed ZIP/inventory validation and native archive/HTTPS OTA upgrade, restart
and rollback checks from Beta 3. These are headless tests, not physical-reader
acceptance. Please report device-specific dialog, layout or navigation issues.

Bookshelf revision: `065f25c06d9a8e0607f29cbe632f4b3d44a8bd37`.
SimpleUI revision: `dd541fc2b384af43287474587622ef68a2fb3185`.
Settings, ornaments and reading progress are retained. Code rollback does not
restore old reading data. Keep a separate backup; see
[OTA recovery](https://github.com/komadorirobin/orbitui.koplugin/blob/v0.1.0-beta.4/docs/OTA.md).
