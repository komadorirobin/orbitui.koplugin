# OrbitUI 0.1.0-alpha.38

Preview release: Bookshelf 5.4.4 and reviewed SimpleUI translation updates,
with OrbitUI's Library/Manga profiles and shelf customizations preserved.

## Changes

- Explicit Auto view mode now supports independent list columns and rows at
  Level 1 and Level 2. Each Library/Manga profile keeps its own values after
  reopening or restarting. Level 2 inherits Level 1 until explicitly changed;
  expanded zoom remains independent and pinch changes only the visible level.
- Face-out favourite books retain their heart/star marker at the top right,
  respecting the chosen favourite-marker preference.
- SimpleUI includes updated Czech and Chinese translations, without runtime
  changes in this follow-up.
- Bookshelf is pinned to `2c8bfd8e53b73b24232e674e12ebc6168963aef5` (5.4.4).
  SimpleUI is pinned to `5bddc5bb7858c2e75a1047b5adfc9c9bbc8e2f1f` (2.7.5).

OrbitUI still displays all shelf books cover-forward. Upstream's new Finished
and On hold orientation reasons do not override that policy. Existing unset
view choices, per-chip captions above/below covers, series slipcases, read/total
badges, completion fading, author ornaments, custom icons and dock/Bento layout
are retained. BookOrbit remains the owner of its synchronization.

## Updating

Use **Uppdatera OrbitUI > Check for updates**, with preview releases enabled.
Install and restart KOReader. Alpha.37 and earlier alpha installations can
update directly through the unchanged bootstrap/API 1. For manual installation,
use `orbitui.koplugin.zip`, not GitHub's source archive.

No artwork, books, reading history or external plugins are changed. This
release adds no settings migration. Keep a settings backup: upgrades from
before alpha.33 still include Bookshelf 5.4's theme-storage migration, which
code rollback does not reverse. Rollback retains the new level preferences;
older code ignores preferences it does not support.

## Validation Scope

Release gates cover sequential full Lua/LuaJIT integration and component
suites, all 42 translation catalogues, sealed runtime packaging,
outgoing-history/artwork checks, and upgrade/rollback from published alpha.37,
including anonymous release discovery and download.

Existing native SQLite/font dependency skips, the absent adjacent Bookends
parity checkout and four external artwork-source audit skips remain. Physical
Bigme acceptance is still outstanding: different list densities at both levels,
Library/Manga independence after pinch/back/restart, and favourite markers
alongside read marks and above/below captions in day/night mode. Headless checks
are not device-level rendering or OTA tests; no performance gain is claimed.
