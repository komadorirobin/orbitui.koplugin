# OrbitUI 0.1.0-alpha.33

Preview release: the reviewed Bookshelf 5.4.0 upstream update.

## Changes

- Integrate 166 Bookshelf commits through `a0bc7e37`: a layered, editable Theme
  library with previews, per-shelf themes, nested shelves, configurable cover
  and group labels, additional progress styles, panel blur and cover panels.
- Adapt theme lookup, editing and navigation to OrbitUI's separate Library and
  Manga profiles without creating duplicate tabs or resetting their settings.
  Ordinary shelf editing now applies changes live and finishes with Close.
- Give each shelf its own ornament deck. Shuffle each shelf once per KOReader
  session; retain manual choices on revisits and isolate manual shelf shuffles.
  Preserve author-matched busts and the one-ordinary-ornament-per-row rule.
  Prevent ornament gestures from intercepting pagination or bottom navigation.
- Retain OrbitUI's cover-forward shelves, adjustable cover sizes, coloured
  series slipcases, read/total badges, finished-box fading and checkmarks,
  transparent labels and dock-aware layout. Existing artwork/icons are unchanged.
- Include upstream fixes for series recent-reading order, fallback covers,
  fonts, search and OPDS descriptions. Bound the new face-out opening pose's
  raw pixel writes and keep the merged repository within LuaJIT's local limit.
- Keep SimpleUI at `f14507af`, external BookOrbit sync ownership and the
  existing Library/Manga roots. The new upstream source API is available for
  future integrations; this is not general UI modularization.

## Updating

Use **Uppdatera OrbitUI > Check for updates**, with preview releases enabled.
Install and restart KOReader. Manual installations use `orbitui.koplugin.zip`,
not GitHub's source archive.

**Back up your KOReader settings before updating.** Bookshelf 5.4 migrates theme
storage. Existing selections are retained, but restoring an older OrbitUI code
version does not reverse this settings migration. Keep the previous installation
and settings backup together if you need to return to the old theme system.

The stable bootstrap and API 1 are unchanged; alpha.32 and earlier alpha
installations can update directly. No book files, reading history, sync data,
artwork or external plugins are changed by this release.

## Validation Scope

Release gates cover full Lua/LuaJIT integration and component suites,
translations, a sealed runtime ZIP, CI and native OTA upgrade/rollback from
the published alpha.32, including anonymous discovery and download.
Headless regressions cover isolated themes/decks, deferred persistence,
cross-profile navigation, ornament session stability, dock boundaries and
clipped opening poses. Existing native SQLite/font dependency skips and four
external artwork-source-cache audit skips remain; artwork is unchanged.

Physical reader acceptance remains open for the migrated appearance, per-profile
theme switching, ornament placement and shuffling, completed series boxes, live
shelf editing, blur in colour/night mode and opening poses at screen edges.
No measured device speedup or device-level settings rollback is claimed.
