# OrbitUI 0.1.0-alpha.36

Preview release: Bookshelf 5.4.1 with OrbitUI's shelf and caption customizations
preserved.

## Changes

- Nested shelves can choose their own theme or return to the parent theme.
  Changing a child does not overwrite its parent's theme.
- OrbitUI retains one per-chip caption menu: long-press a chip and choose
  **Omslagstext > Placering > Ovanför omslaget** (Above the cover), or Bottom.
  Existing text, custom templates and independent Library/Manga/nested-shelf
  preferences remain unchanged in grids, full-screen grids and physical shelves.
  The duplicate upstream grid-only caption picker is hidden while embedded.
- Upstream terminology is now **Cover captions** and **Text size**. Native
  grid-series stacks use a simpler **Show author below series** toggle. An old
  Custom group selection behaves as Author; its template is retained for
  rollback. Physical series-box titles and read/total badges are unaffected.
- Bookshelf is pinned to `7c4c5da6f0668c8f73ee7a791b0c25f149f72a1d` (5.4.1).
  SimpleUI stays at `f14507afdc2cabd36a2ec20a6c3c5dfe0c98a211` (2.7.5).

## Updating

Use **Uppdatera OrbitUI > Check for updates**, with preview releases enabled.
Install and restart KOReader. Alpha.35 and earlier alpha installations can
update directly through the unchanged bootstrap/API 1. For manual installation,
use `orbitui.koplugin.zip`, not GitHub's source archive.

No artwork, books, reading history, sync settings or external plugins are
changed. This merge adds no settings migration. Keep a settings backup:
upgrades from before alpha.33 still include Bookshelf 5.4's theme-storage
migration, which code rollback does not reverse.

## Validation Scope

Release gates cover full Lua/LuaJIT integration and component suites,
translations, sealed runtime packaging, outgoing-history/artwork checks and
upgrade/rollback from the published alpha.35, including anonymous release
discovery and download. Focused tests cover the single caption-picker owner,
legacy/new caption keys and independent child-theme selection.

Existing native SQLite/font dependency skips and four external artwork-source
audit skips remain. Physical-reader acceptance is still outstanding, especially
nested themes, both library profiles, caption content/placement in all views
and the native series-author toggle. Headless checks are not device-level
rendering or OTA tests.
