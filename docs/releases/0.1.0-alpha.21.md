# OrbitUI 0.1.0-alpha.21

Higher gallery frames, author biographies and the Kielce Kafka bust.
**Preview release: physical Bigme appearance, touch and recovery acceptance
remain outstanding.**

## Changes

- Ukiyo-e Gallery frames hang higher, with more clearance above the painted
  shelf surface. A new migration also reaches untouched alpha.20 installations.
  Museum artwork, captions and custom frame positioning are preserved.
- All eleven author busts have offline Swedish information cards about the
  authors' lives, writing and major works. Tap to enlarge and read. Source
  links and image credits are included; the biographies are labelled
  AI-assisted OrbitUI summaries, not copied institutional text.
- Kafka now uses an AI-assisted cutout of the bronze bust in Kielce, retaining
  the bowler hat and bronze colour instead of the invented ivory portrait.
  The photo is by Pawel Ciesla (Staszek Szybki Jest); the sculpture is by
  Anna Wierzchowska-Grabiwoda. Photo/adaptation: CC BY-SA 4.0. The included
  notice distinguishes the photograph license from the sculpture rights and
  records the Polish panorama basis and its limits. This is not a pixel-identical
  documentary reproduction or a worldwide rights-clearance claim.
- The default Kafka image is upgraded only when its checksum is recognized.
  Author matching, biography, zoom and colour are retained. Custom images,
  captions, placement, disabled pieces, native overrides and deleted files
  remain intact. Interrupted upgrades can retry without resetting settings.

No upstream merge in this release. Bookshelf remains at 5.3.1 through `74b825bb`;
SimpleUI remains at 2.7.5 through `b58dfefb`. Navigation, reading data and
synchronization settings are unchanged.

## Updating

Open **Tools > OrbitUI > Uppdatera OrbitUI > Check for updates**, with
**Include preview releases** enabled. Install alpha.21 and restart KOReader.
Alpha.20 and earlier alpha releases can update directly. Bootstrap API 1 and
the stable bootstrap files are unchanged. Allow roughly 250 MiB free space
in addition to existing installations.

Use **orbitui.koplugin.zip**, not GitHub's source archive. The runtime contains
all ornaments, notices and migrations; no separate ornament download is needed.
Do not overwrite customized ornament folders manually to obtain these changes.

[OTA and recovery](https://github.com/komadorirobin/orbitui.koplugin/blob/v0.1.0-alpha.21/docs/OTA.md)
describes safe installation and code rollback. Rollback retains copied artwork,
updated captions and placement metadata; it does not restore the old Kafka PNG
or reset reading progress. Retain backups if you want to restore those assets.

## Verification

Release gates cover both complete Lua/LuaJIT runs: 335 OrbitUI cases, 65 Python
checks, 351 Bookshelf suites and all 13 SimpleUI files, plus 41 translation
catalogs, local comparisons with all 27 museum originals, sealed package
inventory, native OTA from the published alpha.20 installer, downloaded draft
checksums, both CI jobs and anonymous public OTA. Two native-SQLite suites remain
explicit skips; CI lacks the local museum-original cache, so that pixel audit
runs locally. These are headless checks, not physical-device acceptance.

On the Bigme, check frame clearance, Kafka's appearance and base alignment,
tap-to-zoom and scrolling of the longer author texts.
