# OrbitUI 0.1.0-alpha.46

Preview release with rounded cover cutouts for series-box MAL ratings.

## Changes

- The MyAnimeList community rating now sits directly on the series box in
  a **rounded cutout at the cover's upper-left**, instead of a separate sticker.
  The curve and light edge mirror Bookshelf's native count-notch design.
- The cutout follows the width of the **star + score** text. Only that small
  corner is masked: cover size, proportions and box geometry do not change.
  Read/total and **+N** stay above the image, with the series name below.
- Rating text uses the box's own text colour, including in night mode, and
  retains the existing badge font scale. Folder-card badges are unchanged.
- Missing or removed ratings leave no cutout. Very small covers omit both
  text and cutout rather than clip digits. Cached rating updates and unlinking
  take effect on repaint, including with custom series images.
- The existing cached MAL provider is still used. No MAL plugin update,
  personal-score lookup or network request while painting is introduced.

Kanzenban/Paperback/Hardcover choices, natural spine widths and partial box
interiors remain. Upstream pins stay at Bookshelf 5.5.2
`c7a9db2ca1c21ef6a38715e74306fe7f514ba807` and SimpleUI 2.7.5
`7eb80f9e570e6351c55f501f91e1a29c1442b756`. No upstream import, artwork change,
settings migration or reading-data change is included. Existing profiles,
ornaments, icons, sorting and BookOrbit sync ownership are retained.

## Updating

Use **Uppdatera OrbitUI > Check for updates**, with preview releases enabled.
Install and restart KOReader. Alpha.45 and earlier alpha installations use the
same stable bootstrap/API 1. For manual installation choose
`orbitui.koplugin.zip`, not GitHub's source archive.

Keep the previous installation and settings backup. Code rollback to alpha.45
restores the separate rating sticker without changing reading data or settings.
Earlier appearance, theme-storage, grouped-order, ledger and module-edit
rollback caveats still apply.

## Validation Scope

Release gates cover sequential full Lua/LuaJIT integration/component suites,
all 43 translation catalogues, sealed runtime and outgoing-history/artwork
audits, the published alpha.45 installer's upgrade/rollback, both CI jobs,
downloaded draft hashes and anonymous public discovery/download/install.

Focused coverage includes mirrored curved edges, score-dependent widths,
cover aspect, tiny-cover omission, restored corners after unlinking,
day/night ink, custom-image refits, completed series, provider isolation and
text lifecycle. Existing SQLite/native-font skips, absent Bookends checkout
and four external artwork-source audit skips remain. Physical Bigme checks of
the corner, colour/night legibility and interaction remain open; headless tests
and schematic previews are not device acceptance.
