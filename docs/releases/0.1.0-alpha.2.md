# OrbitUI 0.1.0-alpha.2

First public preview of the combined SimpleUI and Bookshelf distribution.
**Not yet device-accepted on the Bigme B7 Pro. Keep a backup and rollback path.**

- Preserves the imported Bookshelf 5.2.2.3 and SimpleUI 2.7.2-beta.5 baselines.
  This release does not merge the newly observed upstream changes.
- Adds a common OTA menu, preview-release support, verified complete-package
  staging and activation on restart. Both legacy installers remain blocked.
- Retains previous code for manual rollback and restores it on the next launch
  if a newly selected runtime fails to complete initialization.
- Includes upstream monitoring and documented integration/merge contracts.

## Install

Download `orbitui.koplugin.zip`, not the source-code archives. Disable standalone
Bookshelf and SimpleUI and restart KOReader before installing/enabling OrbitUI.
Keep their files for rollback. Existing settings and reading data are retained.

This first installation is manual. Afterward use **Tools > OrbitUI > OrbitUI
updates > Check for updates**. Alpha builds include preview releases by default.
The original standalone OTA feeds are unchanged.

See `docs/MIGRATION.md` and `docs/OTA.md` for full installation and recovery steps.
Automated/headless verification does not establish Android UI or suspend/resume
stability. Native SQLite/slow-geometry test skips and seven inherited translation
failures remain documented in `docs/TESTING.md`.
