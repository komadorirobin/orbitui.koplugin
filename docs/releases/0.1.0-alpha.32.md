# OrbitUI 0.1.0-alpha.32

Preview release: the second reviewed SimpleUI upstream update of October 9.

## Changes

- Integrate nine SimpleUI commits through `f14507af`: improved generated covers
  for books without artwork, correctly cropped Cover Deck side covers,
  default/classic folder-stack styles and shared choice/alignment menus.
- Add background-opacity controls alongside the relevant bar and cover-title
  settings. Preserve OrbitUI's transparent titlebar, pagination and cover-title
  defaults, opt-in cover shadows and current reading-info layout.
- Retain BookOrbit Want to Read in the updated source picker and preserve
  unsaved collection changes when opening menus. Choice lists are built only
  when needed rather than while their parent menu is drawn.
- Bound the new shadow-buffer cache and protect other plugins' cover
  replacements when OrbitUI removes its own placeholder hook.
- Include upstream translation updates. Bookshelf remains at `74b825bb`;
  existing series boxes, ornaments, navigation and Manga/Library profiles are
  unchanged.

## Updating

Use **Uppdatera OrbitUI > Check for updates**, with preview releases enabled.
Install and restart KOReader. Manual installations use `orbitui.koplugin.zip`,
not GitHub's source archive.

The stable bootstrap and API 1 are unchanged; alpha.31 and earlier alpha
installations can update directly. Existing books, reading history, sync
ownership, artwork and preferences are preserved. No settings migration or
general UI modularization is included. Code rollback retains settings; older
runtimes ignore the new appearance options.

## Validation Scope

Release gates cover complete Lua/LuaJIT integration and component suites,
translations, a sealed runtime ZIP, CI and native OTA upgrade/rollback from the
published alpha.31, including anonymous discovery and download. Headless tests
cover source menus, defaults, hook ownership, bounded shadow buffers and cropped
placeholder ownership. Existing native SQLite/font dependency skips and four
external artwork-source-cache audit skips remain documented; artwork is unchanged.

Physical reader acceptance remains open for placeholder rendering, folder-stack
styles, day/night shadows and opacity, and external cover-patch coexistence.
No measured device speedup is claimed.
