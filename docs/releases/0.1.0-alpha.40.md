# OrbitUI 0.1.0-alpha.40

Preview release with Bookshelf 5.5, the reviewed SimpleUI updates and the
user-approved trial of AndyHazz's series-box design.

## Changes

- Physical shelves now use Bookshelf's open-topped series slipcases: exposed
  member spines, the first cover as a sticker, and printed series name/read-total.
  Individual spine status marks replace OrbitUI's previous whole-box finished
  checkmark/fade and separate badge. One-volume series remain ordinary books.
  The previous design and tests are preserved on local branch
  `design/orbitui-series-boxes`; no book or reading state is migrated or erased.
- Bookshelf adds explicit author-photo lookup through Open Library/Wikipedia,
  including bulk lookup with Stop. These photos are separate from author bust
  ornaments. New badge choices show pages, percentages or both, with optional
  preference for printed page counts.
- Bookshelf also adds Added or opened sorting, a Recently read micro-module,
  safer page scanning and source-cache invalidation, plus OPDS redirect and
  Hardcover re-linking safeguards.
- SimpleUI adds optional Tabbed Grid modules and a Reader Book quick-settings
  layout, draggable sliders, shared book sources/statistics and cache fixes.
  These layouts do not activate themselves; Classic remains the default.
- Library/Manga profiles, face-out books, per-chip captions/cover sizes,
  ornaments, custom icons, Bento spacing and dock layout are retained. Series
  navigation accepts older saved scopes and keeps rollback-compatible IDs.
- Reviewed pins: Bookshelf `048ab4bad8993ebc713800d884fc485e54753343`
  (5.5.0 plus README follow-up), SimpleUI
  `36e7430f6379693266d1082ae0b9d88de62cb877` (still versioned 2.7.5).

No artwork or external plugins are replaced. BookOrbit remains the owner of
its sync. The old OrbitUI box appearance is not an in-app toggle in this trial.

## Updating

Use **Uppdatera OrbitUI > Check for updates**, with preview releases enabled.
Install and restart KOReader. Alpha.39 and earlier alpha installations can
update through the unchanged bootstrap/API 1. For manual installation use
`orbitui.koplugin.zip`, not GitHub's source archive.

Back up settings and keep the previous installation. Code rollback preserves
reading data, preferences and author photos; it does not backport new grouped
ordering, ledger edits or unsupported module settings to older code. Updates
from before alpha.33 also retain the theme-storage migration caveat: code
rollback does not reverse it. Book files and reading history are not moved.

## Validation Scope

Release gates cover sequential full Lua/LuaJIT integration and component suites,
all 43 translation catalogues, sealed packaging, outgoing-history/artwork
checks, native installer upgrade/rollback from published alpha.39, both CI jobs,
downloaded draft hashes and anonymous public release discovery/download.

Existing SQLite/font dependency skips, absent adjacent Bookends parity checkout
and four external artwork-source audit skips remain. Physical Bigme checks are
still outstanding: new slipcase appearance/completion/restart/navigation;
author-photo lookup and cancellation; page badges; Tabbed Grid and Reader Book
settings; Home/Bento/Library/Manga navigation, icons, colour/night rendering,
ornament/dock clearance, OPDS redirects and scan quarantine. Headless tests do
not establish device rendering or performance; no measured speedup is claimed.
