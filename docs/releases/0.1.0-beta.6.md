# OrbitUI 0.1.0-beta.6

Bookshelf 6.0 and SimpleUI follow-ups, preserving your OrbitUI setup.

OrbitUI includes and adapts **Bookshelf by AndyHazz** and **SimpleUI by
doctorhetfield-cmd**, with their contributors' work. This is an independent
combined plugin, not an official release by either upstream project.

## Changes since Beta 5

- Bookshelf 6.0 adds grid-editable micro-modules, Shelf/Ornament modules among
  books, per-card/panel colours, ornament **Pin here**, and shelf copy/move.
  The new library module editor is separate from SimpleUI's Home/Bento editor.
- **Highlights** in the shared book-detail panel gives access to notes,
  highlights and bookmarks, with an action to view them in the book.
- Persistent cover/progress/ornament/wallpaper/plank caches and partial repaint
  reduce repeated work. Menu/sleep underlay restoration is updated. These changes
  have not been benchmarked on the Bigme; no device speedup is claimed.
- SimpleUI's shared daily-statistics ledger supports Insights, Streak and
  Heatmap; failed/missing database queries remain retryable. Display fixes,
  translations and Critter dialogue updates are included. Most SimpleUI 3.0
  features were already present in Beta 5; this is not a second 3.0 import.
- Retains Home/Bento layouts, scoped shelves, aspect-true series covers,
  bindings, labels, cached MAL ratings and author/series-bound ornaments.
  BookOrbit remains the intended external progress writer; this is not a new
  BookOrbit/MAL sync feature. Component self-updaters stay disabled.
- Module-grid and ornament-deck migrations retain old keys/copies for rollback;
  failed database transactions preserve their source. Existing settings, links,
  reading data, artwork, fonts and the separate add-on channel are retained.

SimpleUI's newly published Git history now accounts for the previously approved
3.0 ZIP snapshot. Both actual upstream Git pins advance; historical source
identity and approval remain in the merge log and Git.

## Install or update

Existing users: use **Tools > OrbitUI > Uppdatera OrbitUI**, enable preview
releases, check for updates and restart KOReader. Beta 5 can update directly;
no bridge is needed. The stable bootstrap and OTA API 1 are unchanged.

For a first installation, download **orbitui.koplugin.zip**, not GitHub's source
archive. **OrbitUI replaces standalone SimpleUI and Bookshelf.** Disable both
and restart first; retain their files/settings for backup. See the
[installation guide](https://github.com/komadorirobin/orbitui.koplugin/blob/v0.1.0-beta.6/README.md#installation).

## Verification and limitations

Release gates cover complete Lua/LuaJIT suites, translations, sealed inventory,
outgoing-history/artwork/secret audits and native OTA upgrade/restart/rollback
from public Beta 5, including downloaded public bytes. Supplemental native
SQLite checks cover deck migration, book facts, OPDS and SimpleUI's ledger.

These are headless tests, not physical-reader acceptance. Bigme checks remain
for existing/new module layouts and rotation, pinning alongside bound ornaments,
series labels/bindings, Highlights from Home/Library, menu/sleep restoration,
day/night/grayscale, statistics after reader/cloud return and external
BookOrbit/MAL/Patch Manager interactions. This remains a prerelease.
